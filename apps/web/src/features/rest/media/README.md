# Break music

The project owner supplied the 10:13 MP3 through the Rental OS PM conversation and authorized reuse in Preview. The local copy is `all-too-well.mp3`. Its SHA-256 is `2c06b9bd5f056434cd80ec76b995607923fcc9451c51b7997d95b07f732ccf5b`; the original download and Rental OS copy remain unchanged.

`all-too-well-cover.jpg` is the same official Red (Taylor’s Version) cover selected in that conversation, reused unchanged from Rental OS. Its SHA-256 is `04bd68a3faa8bc2857df2912ad7a2a28f35b9ca18d26324a53adf5135c258c80`. Album attribution: [Apple Music](https://music.apple.com/cn/album/red-taylors-version-a-message-from-taylor/1590368448). No media is fetched or copied from the active Rental OS directory at runtime.

These two deployment-local files are ignored by Git and excluded from the Registry. Vite includes them in a web build only when they are supplied in this directory; a fresh checkout without them offers local audio selection instead of pretending to play. Local selection creates a browser object URL, uploads nothing and starts the timer when no default source was available. Replacing a playing source or restoring the default preserves the existing break deadline. A single player follows the current identity across the public site, Docs, Demo and administration. Login, logout, identity revision changes or leaving the application release it; ordinary navigation does not.

The default title is Taylor Swift, All Too Well (10 Minute Version) (Taylor's Version). The actual duration and progress always come from the supplied audio; 10-minute breaks stop at 10 minutes and 30-minute breaks repeat until their deadline. The official video thumbnail is an artwork fallback only, not an online audio source. Verify media distribution rights separately before sharing a build containing the recording.
