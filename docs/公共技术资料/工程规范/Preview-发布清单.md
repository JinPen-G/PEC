- 原生 web 构建必须配合正式 API 服务使用，不能用公开静态服务器直接托管 page-assets 或 page-source。

- 发布保留身份、菜单、源码、PRD 和资源隔离的拒绝路径证据；完整发行统一包含 API/web/业务资料，核对迁移兼容、私有备份、健康检查、失败恢复及真实服务器结果。
