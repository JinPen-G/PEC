# Preview 安全指南

维护日期：2026-11-05。维护当前边界与后续约束；实现与证据以代码和专项记录为准。

## 当前运行边界

正式平台使用真实 Cookie 会话、账号角色、项目权限和页面授权。旧 ClientLoginPage、remoteManagement 本机写入服务和 HTML 挂载运行时已经退役。ui/core 演示模式不提供真实身份能力，不能用于受限资料发布。

正式 API 校验身份与项目/页面范围，覆盖菜单清单、预览、源码、需求文档和运行资源。受限菜单不因登录或成员身份而自动开放；授权必须绑定稳定项目/页面/账号身份。目录过滤不能替代接口守卫。项目级 AI 凭证可读取该项目全部允许发布的业务资料，其范围在签发界面单独说明。

## 文件与资料

- 真实 projects、设置、挂载、PRD、客户资料和凭证保持本地边界，不进入公共样例、日志和规范。
- 文件操作复用路径校验，检查相对路径、真实路径与根目录边界，不能用任意浏览器输入替代可信配置。
- 保留原子写入、回滚和失败语义，不将失败显示为空数据、成功或已恢复。
- 未来上传与压缩包处理需补齐归属、路径、大小和资源边界，目录扫描不等于上传已实现。

## 验证与发布

底座检查使用脱敏夹具，原生构建包含明确登记的页面。业务 PRD 保存在受控资料区，研发四册、个人记录和凭证不得进入发行包。权限验收需要实际拒绝路径、撤权和跨项目验证；不能用 UI 不显示或静态检查替代。
