首期：真实账号与项目成员、管理后台、项目/客户端切换、原生空工作台、一个模拟租赁订单列表、同项目鼠标、主动页面/弹窗跟随，以及 Git 触发的自动发布/回退。完整表单等同步、旧 HTML 转换与 Electron 后续再做。

统一入口：浏览器端为单一应用和统一登录，按角色进入 SaaS 管理员式的平台管理工作台或获授权项目工作台；管理员导航直接显示管理功能，不再另设后台站点、后台登录、隐藏入口或身份模式开关。平台 API 仍真实存在，账号/数据继续独立于 Rental OS。

## 不可越过的边界

- Rental OS 的任何东西都不改。只能从固定提交读取，在 Preview 内做来源快照和适配；不在那里安装、构建、改配置、暂存、改数据库或启停服务。
- Preview 独立仓库、依赖、配置、账号数据、进程与发布，不用软链接或 file 依赖其活动工作目录。
- 旧项目 HTML/资料暂不修改、删除或批量迁移，新平台不通过 iframe/HTML 读取演示业务。
- 平台真实管理后端与原型模拟业务分开；同步只呈现受控 UI 状态，不重放真实创建/授权/支付等命令。
- 任何后续完整跟随都不得共享密码、token、密钥或平台真实管理表单。
