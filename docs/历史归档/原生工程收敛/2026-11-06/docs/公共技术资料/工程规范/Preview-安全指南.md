# Preview 安全指南

维护日期：2026-11-05。维护当前边界与后续约束；实现与证据以代码和专项记录为准。

## 当前运行边界

当前没有真实账号、会话和按项目授权。ClientLoginPage 是演示跳转，菜单隐藏不阻止直接访问。Node 服务默认本机可写，remoteManagement 扩大远程写入但不认证访问者；开发接口和静态快照也不是受控的多用户服务。

后续账号产品须在服务端验证身份和项目范围，覆盖清单、API、HTML、文档及资源，不能依赖前端隐藏、缓存字段、角色名称和 URL 参数。这是建设约束，不是当前验收结论。

## 文件与资料

- 真实 projects、设置、挂载、PRD、客户资料和凭证保持本地边界，不进入公共样例、日志和规范。
- 文件操作复用路径校验，检查相对路径、真实路径与根目录边界，不能用任意浏览器输入替代可信配置。
- 保留原子写入、回滚和失败语义，不将失败显示为空数据、成功或已恢复。
- 未来上传与压缩包处理需补齐归属、路径、大小和资源边界，目录扫描不等于上传已实现。

## 验证与发布

底座检查使用脱敏样例；正常 build 和服务包会包含真实项目，执行和发布前核对范围。权限验收需要实际拒绝路径，不能用 UI 不显示或静态检查替代。
