# 伺服器更新與快取

每次執行根目錄的「打包生产包.cmd」，都會產生新的發佈版本。

- 原型 HTML、CSS、JS 和圖片放在 `projects/<項目>/prototype/releases/<版本>/`，相對資源及頁面連結沿用同一版本，避免瀏覽器混用新舊檔案。
- 平台啟動、視窗重新取得焦點及每 60 秒會檢查 `version.json`。發現新版本後，以帶版本參數的入口重新載入，保留當前頁面的路由。
- 網路中斷或版本資訊暫時不可讀時，繼續使用當前頁面。

上傳時先上傳 `assets`、`brand`、`projects` 及 `index.html` 等檔案，**最後上傳 `version.json`**，避免使用者在檔案尚未上傳完成時切換版本。

首次從不含此更新機制的舊版升級時，可開啟 `index.html?_release=<version.json 中的版本>`，繞過舊入口的瀏覽器快取。之後的新版本會自動檢查更新。

已開啟舊版的使用者可能仍在讀取舊版本目錄；清理伺服器舊檔案時，建議至少保留上一個版本至更新完成。
