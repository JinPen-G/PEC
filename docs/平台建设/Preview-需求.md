# Preview 平台建设需求总览

版本：1.1。更新日期：2026-11-05。本册维护平台建设总览和已完成的治理阶段；新原生产品功能唯一来源见[原生原型平台需求](../原生原型平台/原生原型平台-需求.md)。

## 当前方向

Preview 是独立的原型管理产品。新平台有真实账号、项目权限和管理后台；项目业务使用原生 React 页面及模拟数据。项目作为工作空间，客户端是项目内部的展示分面。前端参考 Rental OS 的固定版本成果，但不改动 Rental OS 的任何东西，不共用运行环境。

管理功能采用 SaaS 管理员式的统一入口体验：同一 Preview 应用、同一个登录页，按服务端角色显示平台管理或项目导航；不另设后台站点或后台登录。细则和验收仅在原生专项维护。

首期保留两种文档查看：右上角原 Copilot 位置改为“本页文档”，复用其侧窗阅读文档；原 Agent 工作台菜单改为“文档中心”，个人中心不放入口。文档和相对资源依照项目授权读取，旧 HTML 不因此重新启用。

负责人在治理阶段之后明确调整了原 HTML 导入方案：现有 HTML 暂不修改或迁移，新平台不读取它们承载业务；首期以一个模拟租赁订单列表示例验证，其他未实现内容区留空。新增轻量实时协同和 Git 驱动自动发布，详细角色、流程、范围和验收只在原生专项维护。

## 工程治理阶段

原授权是先整理工程代码、治理规范和文档规则，学习 Rental OS 的共用规则、四册、来源保护与证据维护方式。该阶段已完成，工作项保留在[平台建设任务](Preview-开发任务.md)，实际验证和未验范围见[开发记录](Preview-开发记录.md)。

治理验收包括：共用入口、可导航文档、原文字节追溯、代码/文档边界一致、可运行检查与明确副作用、保留既有行为及未知 WIP。完成治理不等于账号、原生页面或协同已经实现。
