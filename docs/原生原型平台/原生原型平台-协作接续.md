# 原生原型平台协作接续

更新日期：2026-11-08。本册仅内部工程使用。产品合同见[需求](原生原型平台-需求.md)第20–25节，当前工作见[任务](原生原型平台-开发任务.md)第16–21节，阶段证据见[开发记录](原生原型平台-开发记录.md)。

## 目标与边界

多项目React页面与业务需求展示平台。前台使用UIARC布局、动效和主题，后台使用固定Rental OS公共组件。项目只维护基础信息、菜单与用户授权；源码在本地编写，业务需求按明确清单随Git发布，网页只读。公开页匿名可看，受限页由管理员授权，服务端覆盖预览、源码、PRD、资源和AI读取。

原RIMO HTML/PRD、品牌原稿和Rental OS只读。订单与原型业务为模拟交互；账号、授权和项目管理是真实平台能力。内部四册、个人记录、凭据与宿主配置不进入业务资料发行。

## 当前工程入口

- apps/web/src/features/showcase：展示前台、登录、预览/源码/需求、目录和主题。
- apps/web/src/features/platform/PlatformApp.tsx：管理员应用与身份守卫；platform-api.tsx提供请求与查询，PageLayout.tsx提供公共页布局。
- 项目详情为/#/projects/{id}/settings，基础信息、菜单管理与用户授权是同页Tab；侧栏只选中项目管理，已访问面板保留草稿。旧menus/access/config地址兼容重定向。
- 组件中心为/#/center/{projectId}?kind=requirements|components&category=...。一级需求管理/组件管理，二级共享前台分类，右侧按分类列出页面或组件，复用受控需求阅读器。没有组件时显示真实空状态。
- project-core/src/platform负责SQLite、身份、授权和业务资料；platform-server/src/server.js负责HTTP；platform-client/src/client.js负责请求；platform-contracts/src/platform.js维护注册声明。只读HTTP MCP在platform-server中，不恢复已退役stdio包。
- 页面在apps/web/src/project-modules/{project-code}/{page-key}，RIMO目录为rimo-rental。模块稳定键、协议地址和授权身份保持原值；目录改变不迁移数据库。业务资料在project-content，模板为templates/project。
- 后台控件统一从@preview/ui/admin使用，加载从@preview/ui/loading使用。保留Radix底层单例约束和105/156份来源清单，不拼新表格、原生select或裸文字加载。

本地使用npm run dev，web5191/API5190。正式构建使用npm run build:web、npm run build:runtime，发行由scripts/release.mjs、deploy.mjs、supervisor.mjs统一维护。服务器配置在deploy/server，工作流为.github/workflows/release.yml；产物为output/web、runtime、tools、ui、core。
