# 車型組管理

本说明依据营运端既有原型的功能整理，用于页面评审。它不是另行确认的生产接口合同。

## 页面用途

管理不同载具类型的车组基础资料，为车辆建档和车型展示提供品牌、型号、规格及特性信息。

## 列表与查询

列表展示照片位置、品牌与型号、年款、载具类型、特性标签以及编辑和删除操作。支持按品牌或型号搜索；没有符合条件的数据时显示空状态。

## 新增与编辑

- 载具类型包括汽车、摩托车、微电车。
- 先选择载具类型，再显示该类型可用的品牌；改变类型后，清除不再适用的品牌选择。
- 品牌、型号为必填项。
- 可维护年款、国产/进口类型、座位数、排量、油箱容量及行李厢容量。
- 特性标签以逗号分隔，保存时移除空白标签。
- 新增与编辑使用同一表单；取消保留原列表数据。

## 删除与异常

删除需二次确认。取消不改变列表；必填项缺失时不能保存。此原型尚未模拟正式系统的订单关联、车辆引用和删除约束，真实产品应以业务 PRD 的约束为准。

## 原型验收

搜索能改变显示结果；编辑保存后列表更新；新增生成独立车组；删除确认后仅移除目标。操作作用于当前页面内存，刷新恢复合成示例数据，不写真实数据库。
