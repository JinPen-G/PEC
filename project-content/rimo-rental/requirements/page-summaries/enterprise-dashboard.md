从企业、分公司和车辆三个层面查看公务车使用情况，区分资产与员工口径。

- **可用车数不是空闲车数**：仅统计本单位资产车辆中已上架且合约有效的车辆，不含借用他单位车辆。
- **使用率**＝计入口径的实际用车时长 ÷ 有效服务时长；先合计时长，不能平均百分比。
- 默认工作日周一至周五 09:00—18:00；在明细中切换自然日后，卡片、总览和趋势同步切换。
- 较上月同期计算两期使用率差值，展示为带正负号的 %，不是相对增长率。
- 下架中实际用车仍计入分子、分母；历史资料缺失标为“数据不完整”，不能当成 0。
- 明细可以逐车追溯服务流水和用车订单，导出全部筛选结果，不只导出当前分页。
