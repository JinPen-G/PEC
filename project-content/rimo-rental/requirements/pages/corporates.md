# 企业客户管理

## 用途与基本资料

维护企业名称、统一编号、联系人、后台业务账号、签约服务及方案，查询企业范围及状态并进入详情。企业是服务签约和费用归属主体，不能按一个“企业客户”标签推断全部业务权限。

## 服务与身份

签约服务决定员工能否用企业身份预约对应业务。未签约服务的员工仍可用个人身份另判断；本租户会员审核加入企业后获得身份，企业管理员是另一种后台角色。

企业月结费用进入企业账单，不走个人预授权/支付/退款；非月结企业使用企业资格方案，但由客户本人支付。公务车通过合约、配额及分公司预约管理，员工预约不产生个人支付。

## 合作通路

合作通路企业是企业客户中的合作方，可为租车券承担费用。用券人仍是个人会员，不加入合作企业、不切换为员工身份。创建券批次前须核对企业对应挂账能力。

## 维护、历史与验收

新增编辑按权限校验身份及服务，原型中的账号通知只模拟企业业务开通，不修改 Preview 账号。服务与方案修改保留前后记录，不覆盖已有订单企业名称、资格、费用承担和价格快照。

核对企业身份/月结区分、各签约服务和公务合约边界、合作通路用券人关系及历史保护；筛选、导出仅在获准范围。
