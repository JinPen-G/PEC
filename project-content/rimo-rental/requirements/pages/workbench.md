# 工作台首页

## 页面用途

为营运人员集中展示今日待办、车辆与收入概览、资产异常、常用功能和最新公告。工作台提供发现问题和进入业务的入口，不承担新的订单、财务或车辆规则。

## 模块与操作

待办按申请、退款、派车、事故、异常等类型展示紧急程度和当前处理动作。常用功能可编辑选择，导航至新建订单、排程、客户资料和分析等已接入页面。公告展示标题、摘要、发布信息及详情。

## 授权与处理结果

待办、卡片统计及功能入口均以当前账号范围为准；目标业务页面和服务端继续校验状态与操作权限。点击退款或确认方案等不能被视作真实资金或派车成功，模拟处理仅作用于当前演示数据。

## 原型范围

原型包含固定日期、金额及“自动低压管控”“工单”等提示，其中部分能力缺少独立确认的工作流。不能把首页文字推断为完整自动工单、通用审批或已接入车机控制。当前指标样例不取代各业务页的正式公式。

## 验收要点

待办分类、详情、关闭、常用功能编辑/取消和导航可用；处理状态与示例反馈一致。离开页面后的数据保存能力按演示说明，不写真实平台账户或业务数据库。
