# 权限管理：业务分组

## 页面定位

以业务组和共用功能分组呈现角色权限。与权限管理页面使用相同角色、菜单及操作数据，只比较交互组织方式，不形成另一套权限模型。

## 分组与判定

选角色后按业务线、菜单和具体功能定位；共用操作可单独配置。租户业务线授权、账号组织范围、菜单权限与操作权限同时检查。业务组标题、全选及部分勾选仅用于查找，不代表新的授权来源。

## 草稿与操作

新增编辑角色及权限形成草稿，保存成功才更新；重置恢复原配置，不等于撤销所有授权。分组全选限于当前合法候选，不包括隐藏或无权内容。敏感动作及角色变动留操作记录，后端不信任前端自行提交的范围。

## 边界与验收

当前高风险功能按独立权限，不自动启用未来通用审批流。原型调整不修改 Preview 平台用户。验证与普通版同一配置得到相同权限结果、分组查找、部分选择、保存/重置及未授权业务隔离。
