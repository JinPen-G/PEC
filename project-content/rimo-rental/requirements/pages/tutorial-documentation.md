# 公务车教程文档版

## 阅读结构

将同一教程内容按文档式角色目录、章节与步骤呈现。标题、摘要、进入路径、图示和提醒组成一章；目录与选中章节一致。

## 交互与一致性

支持角色选择、关键词搜索、章节跳转和截图放大。切换角色后不保留不属于该角色的章节；搜索无匹配与资源读取失败分别表达。

该页面和其他阅读入口共用教程内容，不能独立改写字段、流程或用车权限。使用角色仅是阅读筛选，不获得真实业务角色。资料更新需同步关联步骤图和说明。

## 验收要点

全文、目录和截图在桌面及手机可读，放大关闭后保持阅读位置；缺失资源明确显示，阅读不写入真实公务车数据。
