# 员工管理

## 用途与范围

管理已经加入企业并审核通过的员工。企业总管理员查看和维护全企业组织、状态；分公司管理员仅查看本公司员工并编辑基础资料及部门归属。

## 列表信息

| 信息组 | 展示内容 |
| --- | --- |
| 员工 | 姓名、身份证号；不显示账号或重复标签前缀 |
| 联系方式 | 手机号、Email |
| 组织 | 所属分公司、部门 |
| 角色与权限 | 员工、主管等 |
| 状态及最近记录 | 启用、停用、最近登录与更新时间 |
| 操作 | 查看详情、编辑、启停等 |

## 组织与预约规则

1. 员工所属分公司决定可用据点、审批设定、订单归属和员工统计归属。
2. 部门用于主管审批、部门用车范围及部门统计。
3. 管理员代建订单时，只能从已审核通过且未停用的员工中选择。
4. 停用员工后不允许新增公务车预约，但不自动取消已有未完成订单；由企业内部协调履约。
5. 当前组织资料的修改不能覆盖创建时的订单及审批快照。

## 验收要点

分公司管理员不能查看或编辑外部公司员工；停用后员工不再出现在有效预约候选项中。列表不混入个人会员方案、个人支付及预授权信息。
