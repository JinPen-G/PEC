# 订单详情

## 信息结构与状态

顶部先展示订单、客户/企业、主状态、资金、派车、风险及行程摘要。业务侧展示客户、承诺车组/实际车辆、预约、取还记录及事件；财务侧展示应收、实收/挂账、收费明细、交易、发票及审计。密集明细按需打开，不重复堆放。

主状态、支付、派车和追缴独立。入口必须同时满足状态、身份、权限及资金条件，来自列表的动作参数不能绕过真实校验。

| 当前阶段 | 主要可用动作 |
| --- | --- |
| 待支付 | 下单预授权确认；失败保持待支付，不记成功流水 |
| 已预订、逾期未取 | 取车、改派；取消或符合条件的爽约/关闭 |
| 验车中 | 持锁者继续取车和获准改派；核验拒绝按专用流程 |
| 用车、续租 | 延长、还车、改派及合法事故操作 |
| 逾期未还 | 补办续租、还车及风险处理 |
| 待结算、补缴、退款 | 继续结算及合法收退，不再取车或续租 |
| 终态 | 历史、费用、备注与打印；后续追缴不恢复履约 |

## 取车与操作锁

点击取车创建锁并进入验车中，关闭未发车窗口保留草稿与锁。只有锁持有人处理关键流程；超时释放需权限，释放取车草稿后按当前时间重判预约、逾期或爽约，不以关窗当取消。

确认发车前核对员工/客户、证件、现场行销资格附件、车辆及硬锁、合约、验车照片/签字和资金。现场方案不合资格改方案并记录差额，不静默套新优惠。客户自付取车补尾款，按履约担保或转租金处理预授权；月结无个人资金步骤。

## 还车与结算

打开还车先建立操作锁，不立即视为已还。未提交验车关闭仍保持用车状态；提交真实还车时间、里程、油电、损伤与签字后进入待结算，车辆进入待整备/管控而不是立即可售。

结算展示租金、里程、续租、逾时及其他有效费用，按基线和事件快照计算。客户自付正差额补缴、负差额退款、平账后确认完成；月结最终费用挂企业，不收个人款。关窗保留已经提交的验车和待结状态，释放还车锁不回滚这些结果。

## 续租、改派与转单

延长或逾期补办先检查当前车辆后续占用与整备缓冲，冲突先改派后单或使用最迟可延长时间。未确认不改时间和状态；成功进入续租并生成增量。必须立即收款的风险场景先成功收款，月结仍只挂账。

派车和同组换车属于履约，不重复扣车组库存；跨车组、升降等或价格变化保存差额与事件快照。免费升等差额为 0 也保存原因和事件。取车中改派须持锁，不覆盖受保护人工结果。

改还车门市仅同车行，确认前检查原门市后续占车，先处理冲突再转单；新门市获得相应履约权限，并按取还门市重算差额。同门市换据点不生异地费。

## 事故、终止与后续费用

未保存事故不改订单；保存按当时阶段和责任处理，费用进入统一费用中心。取消、爽约、拒绝和异常关闭是不同终止原因，校验状态、责任、资金和资源释放，不共用无条件全退。

终态不再取还车、续租、改派。已完成可补事故和追缴；其他终态后续费用也用追缴子状态表达，不改原主状态。企业追加费用按确认挂账时间进自然月，不回改旧关闭账期。个人资金成功、失败及未知结果区分，不用模拟按钮当真实收款凭证。

## 版本、事件及财务记录

订单保留标准价、行销、服务、规则及客户/企业、车辆、门市基线。续租、改租期、改车组、现场换方案和产生差额的转单形成独立事件链；单纯同组换车和换据点不重复生成价格事件。历史版本只读，结算不拿当前主数据重解释旧单。

费用、交易和发票分别记录：预授权不是租金实收，费用新增不是已经收款，登记汇款不是到账。月结不产生个人支付/预授权/退款；发票与支付或账单依据关联，原资料中发票申请入口与全局自动开票口径的差异需另核对。

## 验收要点

每个状态的入口、持锁/关窗恢复、重复提交、资金失败、月结隔离、冲突改派、免费升等、终态追缴与快照保护分别验证，不用页面可点击代替真实业务完成。

## 续租价格来源待确认

延长用车专项要求继承订单计费快照，调价专项要求续租增量采用事件时有效版本。下单基线与历史费用均不能覆盖，续租新增部分采用哪一版本仍需确认。试算、收款及事件记录须按确认后的同一口径核对。
