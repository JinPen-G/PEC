# 新增同站租还订单

## 用途与步骤

营运端代客户建立同站租还订单：选客户及本次个人/企业身份，确定取车据点、车辆和租期，匹配对应价格、方案及服务，校验后提交。与门市下单不同，此模式选择具体车辆而不是只锁车组名额。

## 据点、车辆与资格

取还据点一致，候选须具备且启用同站能力，一般预约只查询开放据点类型。车辆须适用该服务、满足车机绑定、会员载具资格和对应时段可用性；不能只凭实时状态为空闲认定未来无冲突。

微电车免驾照不等于免身份、风控及可用载具判定。企业身份须有当前企业签约服务资格；未签约仍可按个人身份另行判断，不自动借企业资格放行。

## 费用与创建

同站标准价、行销及增值服务与其他模式分别匹配。个人和非月结企业使用预授权及既有结算链路；月结不发起个人预授权、收款或退款。抵扣规则区分当前已上线分时口径与后续规划，不能直接套用新增门市规则。

提交重新检查时段、车辆、资格及未完成订单规则，成功记录具体车辆和价格/方案/客户身份快照。固定演示金额不作为正式默认价。普通订单不享有租车券“不同券可重叠下单”的例外。

## 验收要点

取还据点一致、资格和时间冲突、个人/企业切换及月结资金隔离分别核对。取消或失败不产生已成功订单，也不把试算当最终收款。
