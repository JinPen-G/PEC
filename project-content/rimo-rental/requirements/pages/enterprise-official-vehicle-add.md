# 新增公务车

## 用途与入口

为企业公务车建立基础资料。本独立页面与公务车辆管理中的新增弹窗采用同一字段和规则，不能形成两套互不一致的车辆资料。

## 资料结构

| 资料组 | 内容与规则 |
| --- | --- |
| 车辆身份 | 车牌、车款、类型及车辆基础信息，按表单必填提示校验 |
| 资产与来源 | 企业、资产分公司、车辆来源；资产归属与停放位置分开 |
| 据点与合约 | 来源适用的所在据点、有效合约配额及车辆上架状态 |
| 使用基线 | 当前里程、上架里程，供公务使用量判断 |
| 清洁保养 | 保养母版、清洁母版、上次保养里程/时间、上次清洁时间 |

## 联动与限制

企业自有车只可选择当前企业可用的企业自建据点，营运方车使用平台授权据点；两类来源不交叉。保养、清洁母版只显示企业通用和当前资产分公司专用，换分公司后清除无效选项。

母版不是新车必填项。未配置或基线不足时标为对应提醒资料待补，不自动生成虚构日期和里程；保养、清洁分别判断。上次清洁日期后的已完成公务订单次数由系统累计，不能手填次数。

## 保存与历史

提交前核对表单必填、来源与据点匹配、组织权限及配额有效性。资料保存、有效合约绑定、上架和可预约是不同结果，不把“保存成功”直接等同于预约开放。车辆资料修改不会覆盖已有订单、账单及提醒快照。

## 验收要点

独立页与新增弹窗字段一致；无权组织和不匹配据点不能保存；缺少母版可保存并正确标记待补。保存后提醒页面读取同一组绑定和基线字段。
