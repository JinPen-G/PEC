# 车辆速查表

## 用途与检索

以车辆摘要、实时车况和关注标签发现问题，提供车辆控制台、地图与历史记录入口，不在列表重复控车操作。支持车行/门市/据点多选、汽车/微电车、车牌/VIN/车型/CID关键词及多项关注状态筛选；关注条件按任一命中。

## 关注标签

| 标签 | 条件与限制 |
| --- | --- |
| 通讯异常 | 通讯离线或资料逾时 |
| 定位异常 | 已在线且未逾时，但定位无效；逾时不叠加此标签 |
| 低电量 | 汽车剩油或微电车总电量低于 30%，有效值才判断 |
| 低电压 | 明确上报低压异常；显示在电压后，不重复列标签 |
| 汽车安防异常 | 在线、未逾时、空闲、无订单、无租约前提下判断防盗、中控、车门及钥匙 |

未知值不产生异常标签。同标签只一次，同车多个标签在卡片中只计 1 台。微电车不显示汽车安防标签；单仓温度、电流等未定义异常阈值，不自动设阈值。

## 卡片与定位

监控车辆池清除状态与关注条件；营运中筛选租用中；异常待关注勾选全部关注标签。再次点击当前卡片清除其带入条件。定位地址仅在经纬度有效时可打开地图；更新时间取平台接收时间。

## 历史记录

每次标准化上报按车辆与接收时间保存只读快照。近全屏分页列表不使用展开行；通用字段含时间、GPS/GPRS、坐标、里程、车速、能量、电压及租约，汽车追加引擎、门锁及钥匙，微电车追加马达与各电池仓字段。

按接收时间、关键词及类型适用的状态筛选，旧记录不得被最新状态覆盖。关注标签仅用于识别与筛选，不改变营运、启用、订单或控车权限。

## 验收要点

同车多异常去重、逾时优先、NA 不误报、汽车安防前置条件、微电车类型限制及历史快照分别验证。
