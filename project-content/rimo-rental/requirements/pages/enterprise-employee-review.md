# 员工申请审核

## 用途与权限

审核申请加入企业的员工。企业总管理员查看全企业申请，分公司管理员仅查看本分公司。与营运端会员证件、驾照等资质审核分开，不在此页替代会员资格校验。

## 列表与操作

列表展示申请人姓名及身份证号、手机号及 Email、申请分公司与部门、提交时间、待审核或通过/驳回状态。可查看申请详情并提交单笔或批量审核。

## 审核规则

1. 通过后，员工加入申请的分公司和部门，并出现在员工管理列表。
2. 驳回必须填写原因，驳回者不建立该企业员工身份，不能使用该企业公务车。
3. 批量通过只处理获授权申请；批量驳回必须填写统一原因。
4. 通过审核不意味着自动放行所有车辆，预约仍校验所属分公司据点、车辆状态、有效合约、用车范围和时间冲突。
5. 每次审核保留操作人、结果及操作记录，不覆盖历史。

## 验收要点

未填写驳回原因不能提交；批量选择不能包含无权申请。通过、驳回与员工管理、预约资格联动正确，不因页面角色切换扩大权限。
