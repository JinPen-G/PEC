# 分公司管理

## 用途与权限

维护企业的分公司组织、管理员及公务车使用范围。企业总管理员负责新增、编辑、启用与停用；分公司管理员只能查看本分公司基本资料。

## 页面内容

列表展示分公司名称、管理员姓名与账号、可用据点、员工数、部门数、状态和操作。

| 新建字段 | 必填与说明 |
| --- | --- |
| 分公司名称、管理员姓名 | 必填 |
| 管理员账号、初始密码 | 必填；属于原型业务账号，不是 Preview 平台账号 |
| Email、通知管理员 | 选填；勾选通知后记录通知动作 |
| 用车据点 | 必填；只可从当前企业可用的平台授权据点和企业自建据点中选择 |

## 据点分配规则

1. 平台据点须先由营运端授权给当前企业，再由企业总管理员分配给分公司。
2. 企业自建据点保存后自动加入管理归属分公司的可用据点；总管理员可再分配给其他分公司。
3. 分公司管理员新增本公司的自建据点，只自动加入本公司，不得直接分配给其他分公司。
4. 员工预约车辆时读取员工所属分公司的可用据点；据点停放位置不改变车辆资产归属。

## 启停、历史与异常

分公司停用后禁止新建公务车预约，不自动取消未完成预约或删除历史数据。分公司已关联员工、车辆、订单或账单时不允许物理删除。组织和据点后续调整不能反向改写订单中的历史名称及组织快照。

## 验收要点

- 必填项缺失不能保存；通知动作与资料变更留有记录。
- 新增订单的据点候选项跟随员工分公司，而不是管理员正在查看的分公司。
- 企业外据点、未经企业授权的平台据点不可被选择。
