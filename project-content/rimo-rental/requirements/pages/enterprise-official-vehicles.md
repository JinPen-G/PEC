# 公务车辆管理

## 用途与管理权

管理公务车辆资料、来源、资产分公司、停放据点、合约配额及使用量。总管理员可管理全企业，分公司管理员只能管理本分公司资产车辆，不能因为其他公司车辆停在本公司可用据点而编辑该车。

## 列表与车辆资料

列表组合车牌、车款和类型，资产分公司、据点、车辆来源、当前及上架里程、合约配额、未启用/启用/封存状态及详情、编辑、调拨、停用等操作。新增车辆使用弹窗；独立新增页面沿用相同字段。

累计公务里程以“当前里程 − 上架里程”计算，不等于车辆总里程。任一必要数据缺失显示待补资料；负差值展示 0 并提示异常，不静默隐藏。

## 资产调拨与合约

只有总管理员可调整资产分公司。调拨后原合约配额失效，需由新分公司重新选择有效合约绑定；已预约或用车中订单仍按原快照执行，不自动取消。

员工新预约范围依赖其分公司可用据点、车辆状态、有效合约、用车规则和冲突校验，不以“资产属于员工分公司”作为唯一条件。

## 据点与保养基线

企业自有车只可选择本企业自建据点；营运方车辆只对应平台授权据点，企业端不可编辑营运方车辆据点。本期不开放两类来源混放。

保养、清洁母版不是新增必填项，缺少时分别标为对应资料待补。候选仅包括企业通用及当前资产分公司专用母版；资产调整后无效专用母版清空，企业通用保留。

上次保养日期、里程及上次清洁日期与提醒页面“车辆套用”使用同一组字段，不维护副本。缺清洁资料不妨碍有完整保养资料的提醒计算，反之亦然。

## 验收要点

管理权、资产归属、停放位置及员工预约范围分别验证。资产调拨正确使旧配额失效，历史预约和里程异常提示保留；两个母版绑定入口互相一致。
