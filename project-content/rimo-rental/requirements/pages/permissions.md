# 权限管理

## 用途与结构

维护业务角色及其归属类型、菜单/路由、业务线和共用操作权限。角色列表、所选角色信息、权限树及保存/重置组成页面，不用于配置 Preview 平台账户的真实授权。

## 判定层次

租户业务线授权先决定可用能力，账号绑定组织决定可见数据，角色菜单与功能权限决定查看及操作。不能以某个勾选直接突破未授权业务线或车行、门市范围。

菜单和具体动作分别校验，释放操作锁、费用减免、关闭订单、服务类型强制切换等高风险操作按功能权限，不默认生成尚未上线的通用审批流。业务规则页不重复选择有权角色。

## 编辑与保存

编辑只形成草稿，保存后才生效；重置恢复原角色配置，不等于清空全部真实授权。全选/部分选中对应当前范围，隐藏的无授权业务不能被顺带选中。角色新增、编辑、删除及权限保存需后端范围校验和操作记录。

## 验收要点

不同角色类型及范围隔离、菜单/动作区别、未保存提示、重置、全选与部分状态分别核对。原型演示不能改变真实账号，也不凭角色名字授予无限权。
