# 公务车操作教程

## 阅读目标

按企业管理员、分公司或员工等教程角色组织公务车操作说明。角色来自提供的教程数据，切换阅读角色只切换内容，不改变平台实际登录权限。

## 内容结构

顶部展示教程标题、说明及更新时间。侧栏提供角色、章节目录和搜索，正文显示章节摘要、业务页面路径、逐步操作、截图和提醒。选中章节保持目录定位，查无结果显示明确空状态。

## 截图与规则

截图点开后查看大图，关闭回到原章节。图像的步骤说明和原文件对应，无法加载时提示资源缺失。教程引用的旧页面或示例字段仅用于操作理解，业务规则仍以对应 PRD 为准。

## 验收要点

所有角色和章节可到达，搜索、目录、放大及关闭可用；手机布局不挤压正文。阅读不执行真实创建、审批、支付或车辆操作。无独立功能 PRD 的教程版本保留来源说明。
