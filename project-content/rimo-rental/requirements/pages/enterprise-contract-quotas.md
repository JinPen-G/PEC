# 合约配额管理

## 用途与权限

查看企业公务车合约、分公司配额及车辆绑定。正式合约在营运端建立，企业端不新建正式合约。总管理员可以分配配额及在同企业合约间转移车辆，分公司管理员只查看和使用本公司配额，不创建或取消转移任务。

## 配额与列表

卡片显示有效合约数量、总配额、已分配、未分配和已绑定车辆；点击筛选，再次点击取消。列表展示编号、名称、类型、计费周期、有效期、配额使用、状态及详情/分配/绑定操作。

新增分配不能超过“总配额 − 已分配 − 待执行转入任务预留新增配额”。分公司调减后的配额不得小于已绑定车辆数与任务预留既有空闲配额之和。到期、终止或不可用合约不能新增分配或绑定。

## 车辆转移与容量

来源为生效中、即将到期或已过期且仍有绑定车辆的本企业合约；没有目标时仍可进入来源入口查看原因。目标属于同一企业、不同于来源，且在执行时有效，不接受付款中、终止或作废的合约。

用户按分公司选车辆，不手填转移配额；搜索和取消不得丢失已选车辆。

```text
同分公司可复用配额 = 已分配 − 已绑定 − 其他任务预留既有配额
本次新增配额 = max(0，本次选中车辆 − 可复用配额)
```

各分公司不足部分按列表顺序从目标未分配池扣减；总不足数超出池容量时减少车辆后才能提交。按分公司 ID 合并分配记录，不按名字覆盖。

成功后只改车辆合约绑定；车辆 ID、资产分公司、据点、状态和历史订单不变。来源配额不减，来源合约不自动终止；目标仅补足差额。

## 执行时间、任务与预留

立即转移要求目标当前有效。到期任务时间取“来源结束次日 00:00”和“目标生效时间”的较晚值，须晚于当前且早于目标到期。存在空窗时按来源到期规则停用车辆，之后换约不自动上架。

| 任务状态 | 操作与结果 |
| --- | --- |
| 待执行 | 查看、取消；内容只读，不能原地编辑 |
| 已完成 | 只读快照；立即转移成功直接进入此状态 |
| 执行失败 | 查看原因、取消；没有部分转移 |
| 已取消 | 只读历史 |

同一来源只允许一条待执行任务。保存立即预留目标既有空闲及新增配额，阻止其他分配、绑定和任务重复占用；所选车辆执行或取消前不能解绑、改绑或调拨分公司，但仍可履行已有订单。

确认提交需二次确认及防重，后端重验企业、状态、绑定与容量。执行以同一事务完成配额补足、改绑、释放预留和任务完成；失败整体回滚并释放预留，取消不改车辆及来源配额。后端定时执行不依赖页面打开。

## 历史与待核对项

既有订单、账单保留原合约快照，换约不产生自动退款、补款或账单迁移。原文个别早期验收句仍提“修改任务”，与 v1.2 只读规则不一致；作为待核对差异保留，不补出编辑流程。

## 验收要点

10 台已分配、8 台已绑定的目标分公司，只能复用 2 台；转入 3 辆需新增 1 台。取消释放预留，执行失败无部分变化；跨企业和分公司越权提交拒绝。两端共用任务与绑定结果。
