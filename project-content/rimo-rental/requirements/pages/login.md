# 营运后台登录

## 用途与流程

展示营运人员输入业务账号和密码、查看提示及进入后台的流程。租户和组织范围由实际业务认证上下文确定，不允许用户靠界面参数扩大范围。

## 表单交互

必填输入校验后方可提交；密码显示控制只改变输入可见性。提交状态、失败原因和进入演示页清楚区分，重复点击不重复触发。关闭或修改表单不改变账户身份。

## 登录后范围

营运、车行、门市及据点账号按绑定组织及角色权限读取数据。租户被冻结或停用时不能继续在其后台处理新业务；业务线授权、菜单及高风险操作继续独立检查。

## 当前依据与验收

现有知识库定义角色范围，原型提供交互，但没有完整认证接口、密码复杂度、失败锁定次数及会话期限 PRD。保留该缺口，模拟账号不修改 Preview 用户、密码或授权。

验收必填提示、密码显示、提交反馈和演示导航；真实认证与生产安全策略在业务实现阶段单独核对。
