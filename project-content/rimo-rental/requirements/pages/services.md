# 增值服务管理

## 用途与类型

配置租车附加保险、设备和人工服务。专项 PRD 以门市租车为范围，其他原型页签按各自依据核对，不直接扩展此合同。

| 类型 | 主要规则 |
| --- | --- |
| 保险 | 虚拟权益，通常按天且无实体库存 |
| 设备 | 实物、需归还，按门市管理库存 |
| 服务 | 人工履约，通常按次且无实体库存 |

## 配置与库存

维护名称、唯一编码、类型、图标、会员限制、价格、按天/按次、最大数量、库存开关和启停。未选会员限制表示全部会员。价格非负、最大数量至少 1。

开启库存后配置各门市数量，可用库存为该店总库存减已预订未归还。客户选取车门市后校验该店库存，缺货选项禁用并提示。每单数量仍受最大数量约束。

本期固定门市库存池，不自动处理设备 A 借 B 还的库存流转；需要此能力另确认流程。

## 权限与历史

管理员维护服务、价格与库存；门店经理仅调整本店库存，不能定义、删服务或改价；营运专员只读。删除需二次确认。

服务新增、编辑、启停、价格、资格及库存规则调整生成新版本。订单创建复制 `serviceVersionId`、名称、类型、价格、单位、数量、资格结果和库存口径；后续删除或改价不覆盖旧订单。历史版本只读，订单查看当时命中版本。

## 验收要点

按天/按次费用、会员准入、数量上限、缺货、门市库存权限及订单版本分别核对。价格和库存不借原型权限开关绕过业务校验。
