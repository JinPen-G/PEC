# 车辆控制台

## 用途与类型

查询汽车和微电车的车辆摘要、车机状态、地图定位及指令记录。RIMO 车辆与组织资料负责车辆身份；供应商即时资料负责车机字段，不混造未知字段。汽车 `Vehicle`、微电车 `MicroEV` 与供应商摩托车类别区分。

## 来源与时间

RITI 服务端上报 `IduInfo`、即时及休眠资料，前端不直接调用接收接口。基础资料不覆盖最新车况；即时/休眠资料按 CID 更新，缺失字段不清空已有有效值，每次上报保留原始资料。

| 时间 | 用途 |
| --- | --- |
| `receivedAt` | 平台入库成功时写入，判断新鲜度，不能用刷新时间代替 |
| `sourceTs` | 供应商上报时间，保存用于追查，不替代接收时间 |
| `iduGpsTime` | 最新定位时间，解析失败显示 NA，不借接收时间补值 |

均以 UTC 保存，页面按租户时区显示。

## 状态与颜色

真值为 1、字符串 1 或 true；假值为 0、字符串 0 或 false；空、缺失及 NA 为未知。数值未知不参加阈值比较。

超过 `receivedAt` 10 分钟为逾时；每分钟及新上报后重新计算。汽车通讯在线且未逾时可发控制请求，离线或逾时不可发。一般开关状态用绿/灰，未知用灰；油电 30% 以上为绿、10%—29% 为橙、低于 10% 为红；低压异常为红。

## 汽车控车流程

控车入口先检查车辆、通讯、新鲜度及操作权限；请求由后端调用供应商并保留指令、请求与回覆。真实回覆决定成功或失败，不能在发送后直接改变车况或订单。供应商未上线回覆 `ErrorCode=004` 显示未上线；前端不保存供应商密钥。

有效经纬度才开放地图。车辆身份、定位时间和车机接收时间分别展示；更多状态与指令台账不重复堆入车辆速查表。

## 待核对差异

v1.4 PRD 本期仅展示微电车状态，不开放远程租约指令。当前原型已经有上租约、解租约按钮；是否纳入新一期需负责人确认，不能用原型反向改写已确认范围。信号强度和 TBox 电源状态不在供应商字段中，不得展示虚构值。

## 验收要点

在线、离线、逾时、未知、拒绝及失败回覆分别验证；发送与执行结果分开。坐标缺失不开放地图；类型切换不显示另一类型独有字段。
