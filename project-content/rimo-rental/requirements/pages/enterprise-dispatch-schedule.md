# 车辆调度排程

## 用途与查看范围

以车辆为行、时间为轴查看公务车占用。企业总管理员查看企业全部车辆；分公司管理员查看本分公司资产车辆。其他分公司员工预约本公司的车辆，其预约仍应显示在车辆排程中。

## 查询与时间轴

筛选条件包括分公司、据点、车辆、车款、日期范围及订单状态。

| 订单阶段 | 时间轴起点 | 时间轴终点 |
| --- | --- | --- |
| 已预约、待开始 | 预约取车时间 | 预约还车时间 |
| 用车中 | 实际取车时间 | 预约还车时间 |
| 已完成、提前还车 | 实际取车时间 | 实际还车时间 |
| 已取消、已驳回 | 不显示占用 | 不显示占用 |

## 排程规则

已预约和用车中占用车辆。已完成记录保留为历史排程；提前还车后不继续占用原预约剩余时间。车辆后续资产调拨、名称修改或停用，不覆盖历史订单中的车辆和据点快照。

待审批是否暂占车辆尚需结合审批口径确认；本页不把待审批自动解释为已预约，也不自行定义暂占时限。

## 验收要点

- 预约和实际时间不混用；提前还车正确缩短占用区间。
- 已取消、已驳回记录不参与冲突校验。
- 车辆资产范围和订单员工范围分别处理，不能因为员工来自其他分公司而漏掉本车占用。
