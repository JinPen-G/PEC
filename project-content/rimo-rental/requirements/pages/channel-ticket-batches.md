# 合作通路租车券

## 用途与本期范围

由营运端直接创建或审批企业申报后生成正式批次。合作方可以是旅行社或其他企业，不是独立业务线；用券人仍为个人会员，不因此成为合作企业员工。一期仅同站租还、指定用车时段，固定时长和甲租乙还不启用。

## 创建内容与发券

填写合作企业、批次名称、最早取车与最晚还车时间、可预约期间、适用据点类型/据点、发券方式和名单或数量。合作企业须具备对应费用归属及挂账能力。

名单包含姓名和证件号码，按已认证身份证或入台证匹配；号码先去空白、统一字母大小写，再与当前批次全部名单排重。未匹配保持待发放，后续认证匹配再发放。数量生成产生独立券与兑换码，领取后绑定当前会员。

营运端名单批次可先保存为待导入，不生成券；详情首次补入名单后默认停用，核对后手动启用。企业线上名单申报提交前必须完成校验。

## 批次与编辑规则

待导入、启用、停用是批次状态；待发放/已发放/未领取/已领取与未使用/已使用/过期/作废是券的不同状态轴，不能合并。

正式批次编辑锁定发券方式、状态、数量和名单，不重新生成或覆盖券、兑换码及匹配统计。启停、追加名单和新增券从详情独立操作并记录原因。

## 库存风险

当前需求仅包含未产生有效订单、未过期及未作废券。可用车辆按批次完整用车时段汇总适用据点，扣除已有订单、管控、维修、排程及整备。

相关批次须启用、时间重合且据点相交。计算其在交集据点内的最大可能分配，同时受每批剩余需求和各据点车辆容量限制，不能简单把所有券数相加。

```text
预计剩余车辆 = max(适用据点可用车辆 − 其他相关批次最多占用, 0)
库存风险 = 当前批次剩余需求 > 预计剩余车辆
```

信息不足显示待判断。提醒动态重算，不固化为快照，不预留车辆或阻止保存；实际有车以下单实时查询为准。

## 费用、启停与验收

订单复用同站租还计费，所有费用归合作企业，用券人应付 0，无个人预授权、补款或退款。停用暂停未下单券的发放、领取与新预约，旧订单继续履约；重新启用不恢复已过期券。

验证名单排重、两种发券、正式字段锁定、最坏库存计算、启停再校验及企业费用归属。作废是原 PRD 可选能力，不作为主流程完成的前提。
