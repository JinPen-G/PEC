# 公务车仪表板

## 用途与数据范围

展示员工、资产车辆、订单、用车时长、使用率及排名。总管理员查看全企业或选定分公司，分公司管理员查看本公司。车辆数和使用率按资产归属，员工订单次数和用车时长按员工所属分公司，两者不能混算。

## 指标定义

| 指标 | 统计规则 |
| --- | --- |
| 员工数、可用车员工数 | 在职员工总数 / 在职且用车资格启用人数 |
| 公务车数、可用车数 | 所属资产总数 / 其中已上架且有效合约车辆数；不代表实时空闲数量 |
| 总计用车次数 | 历史累计至当前，不展示累计值较上月百分比，也不重复本月次数 |
| 本月使用率 | 有效用车时长合计 ÷ 有效服务时长合计，保留 1 位小数 |
| 本月用车次数 | 本月创建或发生用车的公务车订单次数 |

指标卡右上角提供统计口径说明。使用率卡图标打开明细，不将整张卡作为入口。

## 使用率计算

工作日口径为周一至周五 09:00—18:00，连续 9 小时，不另扣午休或套节假日历；自然日口径为全天。本月截取至统计时刻。

```text
有效服务区间 =（上架区间 ∪ 实际用车区间）∩ 所选口径时间
计入用车区间 = 实际用车区间 ∩ 所选口径时间
使用率 = 去重后的计入用车时长 ÷ 有效服务时长 × 100%
较上月同期 = 本月使用率 − 上月同期使用率
```

各区间先裁切到统计期间和当时资产归属。下架后仍实际用车的计入口径时间同时补入分子、分母；只有预约而未取车不算用车。公司和分公司先合计时长，再相除，不平均车辆百分比。重叠区间只计一次，时长显示与导出向下取整到分钟。

## 同期与异常

上月同期截取到对应日期相同时分秒；无对应日时取月末相同时刻，完整历史月比较两个完整月。使用率任一期无服务时长显示“—”，有服务无用车显示 0.0%；必要历史缺失显示“数据不完整”，不使用当前状态或预约时间补算。

用车次数较上月采用相对增长比例；上期为 0、本期大于 0 显示“上月无数据”，两期为 0 显示“持平”。此规则不套用到使用率差值。

## 总览、排名与明细

总公司视角列分公司，分公司视角列车辆。无所属车辆时可显示 0 / 0 与“—”，但员工借车记录仍可能存在。部门条形只表达相对大小，不再单独显示伪业务占比。

明细提供工作日/自然日、本月/上月同期切换、车牌搜索、分公司筛选及每页 10 条。无服务时长车辆不进入明细条数。车辆详情另开窗口，含服务流水、用车订单两个 Tab；关闭详情保留清单筛选与页码。

清单 CSV 导出全部筛选车辆；详情导出当前 Tab 全部记录。服务流水保留操作时间、上架/下架、本期计入时长；订单保留真实取还车、完整用车、本期实际和计入时长。

## 验收要点

跨期、月中上下架、资产调拨、跨分公司借车、重叠订单、上月缺日期及无服务分母分别核对。总览、卡片、趋势和导出采用同一口径。
