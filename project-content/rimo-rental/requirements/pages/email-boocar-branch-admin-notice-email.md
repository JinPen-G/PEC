# boocar 分公司账号通知

## 通知用途

向新获授权的分公司管理员说明所属企业、分公司、登录方式和管理范围。正文中的组织名称与账号开通结果保持一致。

## 信息与流程

展示收件人、企业及分公司、企业代码、登录网址、群组、账号和初始密码。首次登录提示修改密码；员工使用企业代码申请加入，再由分公司审核。

分公司管理员可按权限维护本分公司资产车辆、员工和预约规则，不能因为邮件说“管理员”获得企业总管理员能力。邮件中 APP 下载用于员工用车，不与后台登录入口混用。

## 验收要点

企业/分公司不串号，账号与链接对应；长组织名、密码行和按钮在手机可读。预览使用合成值且不实际发送，投递失败不撤销或重复创建账号。
