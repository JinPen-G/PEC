# 租赁业务规则

## 配置范围

维护门市租赁全局的交易、派车、计费和履约规则。具体规则组解锁后编辑，保存生成版本并保留操作人和前后值；取消恢复原配置。释放锁、改价等操作人权限在角色管理配置，此处不重复选角色。

## 交易、库存与派车

下单客户自付采用线上预授权，额度为固定值或租金比例，比例不超过 100%；本期不做下单全额支付。取车可按已启用方式选择履约担保或预授权转租金。月结不执行这些个人资金规则。

待支付在资源保留期内占车组库存，不派具体车辆；默认 30 分钟，到期未确认预授权取消并释放，不计取消费。默认取车前 2 小时复核硬锁、订单间隔 60 分钟；营收/里程/车龄权重合计 100%，默认营收 100%。

## 计费与时间偏差

门市起租 24 小时，余时按小时进位，默认日租 10%/小时，第 5 小时起转一天。标准价不区分平假日，方案按每轮起始时间确定折扣。配置中的固定金额和示例阈值不能代替订单实际命中版本。

提前取车开关与免费宽限分开，宽限内不改原还车时间；超出按商业变化处理。提前还车按是否允许及退完整天数/不退款配置，不把分时提前还车退积分规则套入。

## 操作锁与关闭窗口

| 场景 | 保存结果 |
| --- | --- |
| 开始取车 | 建立锁并进入验车中 |
| 未发车关闭取车窗口 | 保留验车中、草稿和锁 |
| 取车锁授权释放 | 草稿作废，按当前时间重判预约、逾期或爽约 |
| 打开还车 | 建锁，不立即改变主状态 |
| 验车未提交关闭 | 保持原用车状态 |
| 验车已提交关闭 | 保留待结算、补缴、退款；月结保留待结算 |
| 释放还车锁 | 不回滚已经提交的验车和结算快照 |

## 取消、爽约、逾时与续租

免责按下单后时间或取车前提前量判断；有责可固定金额、预授权比例及阶梯配置。越临近取车的档位不能更低，阶梯时间不能重复。爽约按保留车辆时间和自动释放开关处理，不把逾期未取直接当爽约。

超过还车宽限进入逾期，计算新增用车费用及配置罚款、封顶；提交验车后进入结算。续租先校验延长时段和后续缓冲，冲突处理后才能确认；高风险、逾期补办或超阈值客户自付需先收款，企业月结仍挂账。本期不限制单次最大延长天数。

## 版本、校验与验收

所有金额非负，比例 0%—100%，权重合计 100%，时租转日租阈值不超过 24 小时，时间参数非负。客户自付至少启用一种取车资金处理方式。

保存产生 `rentalRuleVersionId`，历史只读。新订单写入基线，商业条件变化形成事件快照；普通保存不重算历史。验收覆盖取消恢复、非法配置、订单基线保护、操作锁中断及月结分支。
