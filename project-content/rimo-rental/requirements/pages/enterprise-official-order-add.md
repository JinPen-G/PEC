# 新增公务订单

## 用途与业务范围

企业管理员代员工建立内部公务车预约。只使用“员工、公务订单、公务车辆”口径，不出现会员方案、订单支付摘要、押金、预授权、退款或个人优惠。

## 选择员工

选择器按分公司、部门及姓名、手机号、身份证号筛选，列表展示员工身份、组织及状态。只可选择审核通过且未停用的员工。选择后带入姓名、手机号、分公司和部门；更换员工后清空据点、车款、车牌、目的地、事由及预约时间。

## 用车表单

| 字段 | 规则 |
| --- | --- |
| 同行人数 | 选填，默认 1 |
| 目的地、用车事由 | 必填；同行人数和目的地位于事由上方 |
| 取车据点 | 必填，从员工分公司可用据点选择 |
| 还车据点 | 默认同取车据点，不能手动修改 |
| 车款、车牌 | 必填，按据点、车款及可用性联动 |
| 预约取车、还车时间 | 必填，还车必须晚于取车 |

## 车辆及提交校验

车辆必须启用并上架、未管控、在员工可用据点、符合部门或员工用车范围、预约时间无冲突，并在需要合约时占用有效配额。选择器返回只是候选结果，提交时必须再次校验，不能用曾经查到车辆代替最终资格。

分公司未开启审批时创建“已预约”；开启时创建“待审批”。保存员工、车辆、据点、预约时间、目的地、事由及审批规则快照，不随后续主数据修改被覆盖。

## 验收要点

更换员工正确重置联动字段；无权员工或车辆不进入候选；缺少必填项、时间反向、车辆已被占用均阻止提交。管理员代建正确采用员工分公司审批设定。
