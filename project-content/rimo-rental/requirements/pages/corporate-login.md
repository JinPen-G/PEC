# 企业服务登录

## 入口用途

保留营运端资料包中的企业登录展示，供查看企业客户开通后的登录样式。与企业端登录页使用同一业务角色口径，来源位置不同不表示新增一类身份或认证服务。

## 表单与结果

账号、密码按必填校验，提交时区分处理中、失败与模拟成功；密码显示切换不保存额外明文资料。成功后进入企业演示内容，不能通过 URL 自行更换成其他企业身份。

## 数据与权限

企业总管理员管理本企业，分公司管理员只处理本公司范围；普通员工不因有企业身份获得后台管理权。企业签约服务和公务车配额继续决定业务可用性，登录不是全部功能放行条件。

## 依据与验收

该页面没有独立的会话或找回密码 PRD；界面中的固定账号仅用于演示。校验、提交反馈、导航及角色边界需清楚呈现，不修改 Preview 的真实账号或授权。
