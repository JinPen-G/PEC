# 租车券申报审批

## 用途与对象

营运人员处理合作企业提交的批次申报。申报记录企业填写的活动、时段、发券方式及名单/数量，在审批通过前不是批次，也不生成券或兑换码。

## 查询与定位

| 查询条件 | 用途 |
| --- | --- |
| 申报单号 / 批次名称 | 定位一笔申报或活动 |
| 申报企业 | 查看指定合作企业提交的记录 |
| 申报状态 | 区分待审批、已通过、已驳回和已撤回 |
| 发券方式 | 区分名单发放与数量生成 |

筛选与排序、显示列位于同一工具栏。空间不足时，次要条件收纳到“更多搜索”；收起后已选条件仍然有效。列表同时展示申报编号及版本、批次与企业、发券方式及数量、据点配置、固定取还时间、提交人和状态。查看一条记录后，再根据其当前状态进入审批或关联批次。

## 审批内容

查看申报编号、企业、批次名称、指定时段、可预约期间、发券方式、名单校验或数量、申报版本和历史。审批时核对合作企业的费用归属及挂账能力，绑定适用据点类型与据点；企业申报不能自行指定营运内部资源。

| 申报状态 | 操作 |
| --- | --- |
| 草稿 | 企业编辑并提交 |
| 待审批 | 营运通过或驳回；企业在未进入审批处理前可撤回 |
| 已驳回 | 企业查看原因、修改后按新版本重提 |
| 已通过 | 查看关联正式批次，原申报不再编辑 |

撤回保留填写内容并转回可编辑草稿，不混成批次停用。

## 提交与生成

名单方式提交前姓名、证件号及重复校验完整；审批不绕过名单异常。通过和生成正式批次在同一事务完成，重复请求不能重复生成。保存正式批次 ID 与编号，企业统一列表只展示生成的正式批次，不重复另列通过申报。驳回保留原因，不发券。

## 历史与验收

驳回或撤回后重提沿用编号、新增申报版本，旧内容与审批记录不覆盖。通过后正式批次追加和启停走批次详情，不通过重审已通过申报实现。验证重复审批、并发撤回、异常名单、未具备挂账能力及据点越权。
