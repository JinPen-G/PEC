# 车型组管理

## 用途与概念

维护真实车辆的品牌、型号、年款和规格，供车辆档案选择。此页的车型基础资料与“基础产品定价”中的销售产品组不同：前者描述车辆，后者组合车型、标准价及里程规则。

## 列表与检索

列表展示照片、品牌/型号、年款、载具类型、特性和编辑/删除操作。关键词按品牌或型号搜索；无匹配记录显示空状态，不以其他车型填充。

## 新增与编辑

| 资料 | 规则 |
| --- | --- |
| 载具类型 | 汽车、摩托车、微电车，与会员可用载具及预约校验保持统一 |
| 品牌、型号 | 必填；品牌候选按载具过滤，切换载具清除无效品牌 |
| 年款、国产/进口 | 按车辆实际规格维护 |
| 座位、排量、油箱、行李厢容量 | 对应车型属性，不用缺失值伪装为 0 |
| 特性标签、照片 | 便于识别；标签清理空白，照片使用可用资料或明确占位 |

新增与编辑使用相同表单，保存更新目标资料；取消不改变原记录。页面不配置标准价、行销方案或正式可租资格。

## 删除与当前范围

删除须二次确认，取消不改变数据。原型仅模拟移除记录；知识库未给出该页完整的车辆引用、历史订单关联和物理删除接口合同，因此不能以演示删除成功推断生产系统允许删除被引用车型。

## 验收要点

搜索、类型与品牌联动、必填提示、编辑保存及取消分别可用。载具类型统一使用“摩托车”，不与供应商微电车类别混用。页面内示例修改不写真实租赁数据库。
