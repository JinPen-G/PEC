# 新增门市租车订单

## 创建流程

选择客户及个人/企业预订 → 选择取还门市和时间 → 选择车组 → 增值服务 → 行销及抵扣 → 试算 → 预授权或月结 → 创建订单。客户面向服务门市，不直接选择备车停车据点；自助业务按具体自助据点另行判断。

## 表单与联动

| 内容 | 规则 |
| --- | --- |
| 客户与身份 | 客户必选，默认个人；客户有企业关系才可切换企业预订 |
| 取还门市与时间 | 必填；默认次日 09:00 取车、次日同刻还车，还车晚于取车 |
| 车组 | 按门市服务范围、时间及车组实时库存选择，无库存禁选 |
| 增值服务 | 按天/按次及数量计费，设备检查取车门市库存和限购 |
| 优惠 | 个人：方案、积分、优惠券；企业：仅企业资格方案 |
| 收款 | 预授权押金、暂不收款、企业月结；全额支付不在本期 |

现场核验方案提示“取车需核验证件”并保存资格和证明要求。取还门市不同才判异地费用，同门市不同停车据点不重复加调度费。

## 租金与库存

起租 24 小时，余时不足 1 小时进位，每小时按日标准价 10%，第 5 小时起算一天。标准价不分平假日，方案按每轮 24 小时起点决定折扣。

订单占一个车组库存名额，不叠加具体车牌重复扣减；目标时间窗含前后整备缓冲。创建后派车状态待派车，预订成功再进入预分配和硬锁流程。

暂不收款为待支付，占库存但不进入具体派车；默认保留 30 分钟，采用订单规则快照。保留期内预授权确认后变已预订，超时取消并释放库存，不产生取消费。

## 身份、资金与快照

个人及非月结企业预订按客户自付，下单只线上预授权，比例不超过 100%；取车另补尾款。月结订单不产生个人预授权或支付，最终费用入企业账单。

创建与库存占用须重新校验资格、车组和设备库存，不能仅依赖页面试算。订单保存标准价、行销、服务、里程和规则版本及客户/企业、门市、车型等基线；后续改配置不回改，商业变化生成事件差额。

## 验收要点

身份切换正确清理不适用抵扣；无库存、时间倒置、失效资格拒绝创建。月结无个人资金入口；支付失败不生成成功资金流水，待支付到期正确释放资源。
