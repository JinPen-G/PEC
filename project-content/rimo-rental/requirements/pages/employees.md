# 平台业务账户管理

## 页面用途

维护租户营运方员工及车行/门市/据点业务账号、部门、角色、联系方式和启停。与企业端“员工申请审核”和 Preview 平台真实用户管理分开。

## 组织及列表

按营运部门或车行结构筛选，查询姓名/账号、组织、角色、手机/Email、状态及最近登录。角色归属类型决定需要绑定的营运、车行、门市或据点范围，不因角色名称扩大可见数据。

## 权限与操作

账号启用、角色权限、服务业务线授权和数据范围共同决定可用能力。新增编辑、批量启停、角色调整、导入导出及密码重置各按功能权限及目标范围校验，敏感动作保留记录。

车行账号只处理绑定车行，门市只处理本门市，据点按对应功能权限处理指定范围。统计和导出同样过滤权限，不用列表隐藏代替后端保护。

## 已知范围与验收

原型演示账号和密码流程，不连接真实业务认证，也不能重置 Preview 的平台密码。现有资料未提供独立账号生命周期、批量导入失败回滚及密码复杂度合同，不凭控件补出规则。

核对组织范围、角色联动、启停及取消、批量只作用获准记录；账号资料与企业会员关系不混用。
