# 公务车教程维护

## 维护范围

编辑教程标题、副标题、更新时间、整体说明、角色名称和说明、章节、路径、步骤及截图说明。与阅读版共享资料结构，不能改成互不兼容格式。

## 目录与草稿

角色和章节可新增、选择、调整内容及删除，删除前确认影响，不能留下无效选中项。编辑时显示当前章节预览；取消只退出本次草稿，不覆盖已应用内容。

## 导入与导出

导入 JSON 先检查顶层、角色、章节和步骤类型，验证失败保留当前内容并显示问题。导出完整当前教程及资源引用，保留稳定标识，不能只导出可见章节或搜索结果。

原维护页通过目录绑定写 JSON；本轮原目录只读，接入页采用文件导入与独立导出，用户可保存新的副本。资源引用继续使用当前受控资产，不修改原截图。

## 验收要点

整体设置、角色/章节新增删除、步骤修改、取消、合法及错误 JSON 导入、完整导出分别核对。导出的数据可被阅读版加载；操作不会改写 RIMORental 源目录。
