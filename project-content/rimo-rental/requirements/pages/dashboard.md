# 综合仪表板

## 页面用途

营运商总览会员规模、企业客户、车队状态、今日订单、预估收入及近期趋势，辅助定位业务异常。适用范围以账号可查看的租户、车行或门市为准。

## 显示与交互

顶部组合会员/企业、车辆总数及租用/待租/维保、今日订单及业务分项、预估收入。中间地图支持热力与据点分布，趋势展示近 7 天出租率以及收入和订单量。页面中的提示或待办窗口可查看和关闭，不修改真实营运状态。

## 指标边界

现有资料没有本页独立的完整指标公式、结算截止和回溯口径。固定的本周增量、较昨日比例、更新时间及图表数据是原型示例，不能据其生成新的财务规则。

营收、应收、实收和企业挂账分别处理；当前车辆分布与企业公务车的历史时长使用率不共用公式。数据权限同时覆盖卡片、地图、明细和导出，不因聚合图表而显示外部组织。

## 验收要点

两种地图视图与图表正常显示，卡片与提示可操作；无数据与加载失败明确区分。后续接入真实指标前补齐公式、时区、统计范围和来源，图表当前不作为真实经营报表。
