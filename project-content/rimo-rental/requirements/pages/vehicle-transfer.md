# 车辆调拨管理

## 用途与范围

查看车辆当前据点、服务类型和状态，配置同业务据点调整或跨服务类型调拨。此页侧重位置与服务配置，不是订单人工改派，也不执行企业公务车资产分公司变更。

## 查询与配置

支持车牌/车型关键词、当前据点和服务类型筛选。原型对空闲车辆开放单车或多选操作，不可操作记录显示禁用。单车抽屉带入当前资料；批量可以统一设置目标服务与据点，再逐车检查。

## 核心规则

1. 目标据点必须支持目标服务类型，切换服务后不能保留不适用据点。
2. 当前和目标均相同不计为执行车辆。缺目标、无实际变化时不能确认。
3. 普通调拨只改变当前位置和本次服务配置，不改变资产车行，也不把车辆转入另一车行库存池。
4. 本期不支持跨车行车辆调拨、借调和库存共享；真实执行还须核对时间窗、订单占用及整备状态。
5. 已有预约和费用历史继续使用快照，不自动取消或改写；配置取消不改变原车辆。

## 原型与需求差异

当前原型仅演示内存中的空闲车辆变更，尚不足以证明车行范围、未来占用及服务能力已全部实现服务端校验。树形据点候选不能作为正式跨车行权限依据；差异需在接入验收时逐项核对。

## 验收要点

单车与批量操作结果一致；统一设置仍可逐车修改，执行数量只包含变化项。缺目标或不匹配服务拒绝；取消不改数据。跨车行边界与后续预约不能被界面选择绕过。
