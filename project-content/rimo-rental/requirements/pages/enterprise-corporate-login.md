# 企业端登录

## 页面用途

展示企业管理员进入公务车后台的登录流程。此页的用户名、密码及登录反馈是业务原型数据，与 Preview 的真实登录和用户授权隔离。

## 页面流程

输入账号和密码，按页面必填校验后显示模拟登录反馈，进入企业端演示页面。登录错误应明确显示，不把错误状态当成成功。页面中的记住登录或密码辅助入口只表达原型效果，不承担真实密码找回、账户开通或身份认证。

## 业务身份

企业总管理员查看和管理本企业全量数据；分公司管理员只处理本分公司授权范围。员工身份及会员身份不等于后台管理员。租户、企业和分公司上下文应由实际认证服务提供，不能以客户端下拉或 URL 参数自行扩大组织范围。

## 已知范围

现有资料未提供此登录页独立的账号锁定次数、密码复杂度、会话期限及找回密码接口合同，这些不能按原型控件反推为正式规则。页面资料整理保留此缺口，实际认证另按经确认需求实现。

## 验收要点

必填提示、失败反馈、密码显示控制及进入演示页可用；模拟账号输入不修改 Preview 账号、项目授权或真实企业用户。
