# 个人会员管理

## 用途与身份

查询会员、联系资料、方案、企业关系和账户状态。会员注册后首先拥有个人身份，在本租户内加入企业并审核通过后才取得企业身份；不把企业身份理解为独立账号或后台管理员。

## 列表与操作

按关键词、状态、企业及页面筛选查询，展示会员标识、姓名/账号、手机/Email、证件、当前方案、企业加入状态及账户状态。可进入详情、编辑、方案管理和获准状态操作；批量或导出也按账号数据范围处理。

## 资格与状态

正常、停权、冻结、黑名单及封存等页面状态须与相应业务操作分开，原型按钮不代替真实后台状态合同。会员可用载具包括汽车、摩托车、微电车；免驾照的微电车仍须有对应载具资格并通过账号风控，不因审核关闭无条件放行。

## 方案、企业与历史

个人方案与企业方案分别用于匹配价格权益。企业是否签约服务及是否月结是额外条件，不按“已加入企业”直接认定可用全部服务或不用付款。

会员、证件、方案和企业关系变更需权限与操作记录；旧订单保留创建时姓名、等级、身份及计费资格，不随当前会员资料反向改变。

## 验收要点

筛选与统计采用同一授权范围；单一会员身份和企业关系正确表达。状态操作、资格及方案分开，取消编辑不改原资料，历史订单保留快照。原型新增或冻结不会修改 Preview 平台账户。
