# 预约审批设定

## 用途与范围

按分公司控制公务车预约的审批要求。企业总管理员配置企业内全部分公司，分公司管理员仅配置本分公司；不建立通用可配置审批流。

## 配置内容

| 配置 | 规则 |
| --- | --- |
| 分公司 | 以用车员工的组织归属匹配，不以车辆资产归属或取车据点匹配 |
| 预约审批 | 开启或关闭 |
| 审批人 | 员工部门主管；分公司管理员也可在后台审核 |
| 状态 | 控制当前配置是否生效 |

## 预约与审批流程

1. 员工或管理员代员工提交预约，先校验员工、车辆、据点、有效合约、用车范围和时间冲突。
2. 未开启审批时，校验通过后进入“已预约”。开启时进入“待审批”，推送给员工部门主管。
3. 审批通过后进入“已预约”并占用车辆排程；驳回后进入“已驳回”，不占排程。
4. 结果通知预约员工；订单保存创建时的审批规则及结果快照。

## 状态与边界

待审批不能直接等同于最终有效预约。原 PRD 对“提交时暂占车辆”保留条件性描述，未给出统一暂占期限及释放规则；需确认采用哪一种方式，不能自行补充。修改当前审批设定不覆盖已有订单的审批快照。

## 验收要点

- 开关分别产生待审批、已预约状态；管理员代建订单使用相同判定。
- 分公司管理员不能读取或修改其他分公司的设定。
- 驳回订单不出现在有效占用排程，结果通知和历史记录可追溯。
