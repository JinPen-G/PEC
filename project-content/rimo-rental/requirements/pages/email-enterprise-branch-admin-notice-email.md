# 企业分公司管理员通知

## 通知对象

向企业指定分公司的管理员说明授权结果及登录信息。企业服务版本保留通用管理文案，不混入 boocar 专用下载或未签约公务车能力。

## 展示内容

按问候、企业/分公司授权说明、企业代码、登录网址、群组、账号、初始密码和登录按钮排列。所属人员用企业代码申请，实际审核按业务流程进行；初始密码明确提示首次修改。

## 权限与投递

管理员只能处理实际授权的分公司及功能范围，不能从邮件标题推定总管理员权限。通知失败记录到统一通知服务，不把未投递当授权失败，也不重复创建管理员。

## 验收要点

企业、分公司、账号及链接变量一致；移动端长文本可读。展示页用合成信息，不发送真实邮件或改变 Preview 账户和权限。
