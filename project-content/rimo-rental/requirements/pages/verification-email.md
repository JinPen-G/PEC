# 验证码邮件

## 使用场景

在需要验证用户邮箱的注册或相关操作中，展示租户发送的验证码通知。预览保留邮件正文结构，变量替换不引入真实账号资料。

## 变量与文案

| 变量 | 展示位置与规则 |
| --- | --- |
| `tenant_group` | 邮件标题、发送主体及署名，保持一致 |
| `verification_purpose` | 说明本次需要验证的操作，不与其他场景混用 |
| `verification_code` | 高亮验证码，按字符串保留前导零 |

正文说明在 5 分钟内按业务页面提示完成验证，不将验证码提供给他人。邮件不要求回复密码，也不提供额外付款或账户操作。

## 展示与验收

桌面及手机保持正文可读，长租户名不遮挡验证码，代码不被千位分隔或科学计数法改写。变量未提供时应明确提示模板资料未完整，不能发送未替换正文。当前页面使用合成示例，真实验证码生成、校验与失效由认证服务实现。
