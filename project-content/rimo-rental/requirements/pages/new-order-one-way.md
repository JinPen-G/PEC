# 新增甲租乙还订单

## 用途与流程

选择客户及身份、取车据点、可还据点、具体车辆和租期，匹配甲租乙还价格、行销及费用后提交。此模式与同站、门市定价及库存规则分开。

## 据点与空位

据点甲租乙还能力启用后支持取还，但目的地查询还须空闲车位大于 0。不能因能力已开启就忽略实时空位，亦不改变旧 APP 查询字段含义和扣减时机。

## 费用与资格

按地区表与地区间规则计算调度费，可以加收或减免。停车优惠以系统查询可用结果显示，原型自动返回字段不设计成任意手填减免。个人及非月结企业按现有预授权链路处理；月结不发起个人资金操作。

会员可用载具、企业签约服务、车辆服务类型、车机绑定和订单时间窗共同检查。企业身份与月结是不同维度；未完成订单卡控仍按普通分时规则，不套用租车券多单例外。

## 提交与历史

提交再次校验目的据点、车辆和资格，保存当时客户身份、取还地点、地区费用及计费规则快照。车辆和据点随后变化不重写历史。失败或取消保持未创建结果，不以模拟成功代替实际可用性。

## 验收要点

目的地空位为 0、能力暂停、地区费用加减、自动停车优惠、身份/月结及车辆冲突分别验证。页面支持不同据点，不扩展为跨车行门市派车能力。
