# 公务订单管理

## 用途与范围

查询企业员工的公务车预约、审批及实际用车记录。企业总管理员可查看全企业订单，分公司管理员只查看本公司员工订单；跨分公司使用车辆时，订单仍归属于用车员工分公司。

## 查询与展示

筛选订单编号、员工姓名或手机号、分公司、部门、订单状态、审批状态、预约时间、取车据点及车辆。列表和详情组合展示员工及组织、车辆、据点、预约取还时间、实际取还时间、审批结果和当前业务状态。

## 关键规则

1. 公务车只用于企业内部员工，不按个人会员租赁计费。
2. 已完成订单显示实际取还时间，不能用预约时间替代真实发生时间。
3. 已预约和用车中按相应时间占排程；取消和驳回后不占车辆。
4. 员工跨分公司据点借用车辆，订单归属、审批及员工统计仍按员工所属分公司。
5. 创建时保存员工、车辆、据点、组织与审批快照；车辆调拨、停用、改名或组织调整不反向覆盖历史。

## 状态与异常

保留预约、待审批、用车中、已完成及取消/驳回等状态差异；待审批的暂占方式需按审批合同确认。合约失效、员工停用或车辆调拨不自动取消已有预约，由企业内部协调既有履约。

## 验收要点

总管理员与分公司管理员的数据范围不同；取消及驳回订单不出现在占用排程；历史名称和实际时间可追溯。页面不混入个人会员付款、预授权及退款操作。
