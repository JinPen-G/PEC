# 租车券预约 APP

## 入口与领取

在同站租还附近提供“使用租车券”，与普通优惠券分开。会员选择我的券或输入兑换码。只显示当前账号已发放/领取、未使用、未过期、未作废且批次启用的券；同账号多券逐张展示。

兑换时检查代码存在、未领取、未使用、未过期、未作废、批次启用及当前可用期间，通过后绑定当前账号，不允许换号重复领取。

## 预约时间与车辆

```text
预约取车时间 >= 批次最早取车时间
预约取车时间 < 批次最晚还车时间
预约还车时间 = 批次最晚还车时间
```

取车时间由 APP 确定并提交，后端校验，不用后端擅自生成替代值。服务固定同站租还，不能修改最晚还车时间；在预约页只读显示最终取还时间。

据点与车辆限定批次配置，可以包含不开放一般预约的专用据点。按本次完整时段实时查询车辆并校验会员可用载具类型；微电车免驾照不等于免账户、风控和载具资格校验。

## 创建与费用

提交时重新校验券归当前账号、状态、批次、期间、据点、车辆及资格，创建订单与券标记已使用同事务完成。不同券可用于同账号时间重叠订单，但必须分别绑定不同车辆，每券仅一笔有效订单；普通订单限制不因此放宽。

用券人应付 0，所有正常及异常费用归合作企业。页面不显示企业月结术语，不开放个人预授权、支付、补款、退款、优惠/积分或加购。

## 取消及异常

订单取消保留领取/发放状态，使用状态恢复未使用；重约再次校验有效期和批次。无车、券已用/过期/作废、批次停用、账号不匹配及资格不足分别提示，不能自动更换普通付费订单。逾时还车不因客户未付款被阻断，费用仍归合作企业。

## 验收要点

时间边界、账号归属、重复领取/提交、同账号不同券、无车及取消复原分别验证。固定时长模式本期禁用，不按原型预留解释为已上线。
