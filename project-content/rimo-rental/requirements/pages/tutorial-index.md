# 公务车教程目录

## 页面定位

作为公开教程入口，以当前目录布局阅读同一份公务车角色、章节和步骤数据。与原阅读版的差别在界面组织，不维护另一套业务规则。

## 导航与内容

角色切换后展示该角色可读章节，当前章节不存在时进入有效首项；关键词按当前角色搜索。目录选中与正文一致，正文包含摘要、操作路径、步骤、截图及注意事项。

## 资源与阅读

截图来自已整理的教程资源，可放大并返回。加载失败和没有匹配章节分别显示；当前截图若与 PRD 有差异保留核对提示，不从图像反推业务要求。

## 验收要点

入口、角色切换、章节搜索、图片放大及移动阅读正常。阅读角色不改变真实账户授权，页面不直接触发公务车操作。
