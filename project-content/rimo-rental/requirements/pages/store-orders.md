# 门市租赁订单

## 页面用途

按门市租车及获授权的 24 小时自助业务查询订单，快速进入取还车、续租、结算或异常处理。页面由统计、筛选、业务页签、订单表及分页构成。

## 查询与列表

关键词包括订单、姓名、手机号、证件、企业和车牌；筛选客户类型、状态组或具体状态、预计取车/下单时间口径、取还门市、车组/车型、月结、追缴与风险。默认创建时间倒序，行程可按取还时间排序。

列表组合订单、客户/企业、承诺车组及实际车型/车牌、预约时间、取还门市及据点、金额、主状态和操作。未派车只展示车组与待派，金额下方最多一项资金标签。企业身份不代表月结，非月结企业仍走客户自付。

## 状态与动作

| 阶段 | 状态与主要操作 |
| --- | --- |
| 待处理 | 待支付、已预订、逾期未取；预授权、取车、取消或符合条件的爽约 |
| 履约 | 验车、用车、续租；继续取车、延长、还车、改派 |
| 异常 | 逾期未还、出险处理；联系、补办续租、事故处理 |
| 结算 | 待结算、待补缴、待退款；继续结算及合法收退 |
| 终态 | 完成、取消、爽约、拒绝、关闭；不再继续履约，后续费用走追缴 |

快捷动作带订单 ID、状态、资金、企业/月结及目标动作进入详情，自动打开对应流程；URL 演示入参不替代真实权限或订单状态校验。

## 统计、费用与历史

统计按当前获准业务线，卡片作为独立条件不覆盖普通筛选；不能沿用其他页面清空筛选的行为。无授权业务页签不展示。

月结始终标企业月结，不提供个人支付、预授权和退款。非月结追加费用优先显示追缴。取还门市不同判异地，同门市换停车据点不加异地费。追缴不改变原终态。

历史客户、车组、门市和车牌读快照，当前 ID 可用于筛选但不覆盖历史名称。

## 验收要点

按钮与状态、资金及权限一致；多状态轴不混用，快捷跳转恢复正确流程。统计、分页和导出不包含无权数据，终态只读和月结资金隔离明确。
