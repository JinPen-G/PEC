## 1. 页面范围

原型页面：`02_原型和PRD/原型/企业端/dashboard.html`

页面用途：展示企业公务车运营概览，包括员工、车辆、订单、用车时长、使用率、分公司使用状况、部门用车统计和排名数据。

## 2. 查看范围

1. 企业总管理员查看企业全量数据。
2. 企业总管理员选择总公司范围时，分公司使用状况展示各分公司数据。
3. 企业总管理员选择某一分公司时，分公司使用状况展示该分公司内车辆数据。
4. 分公司管理员默认查看本分公司数据。

## 3. 顶部指标卡

| 指标 | 口径 | 展示规则 |
| --- | --- | --- |
| 员工数 | 当前查看范围内所有在职员工数量，不受用车资格状态影响 | 显示在职员工总数 |
| 可用车员工数 | 当前查看范围内在职且用车资格为“启用”的员工数量 | 显示具备用车资格的在职员工数量 |
| 公务车数 | 当前查看范围内按资产归属统计的公务车数量，不受合约与上架状态影响 | 显示所属公务车总数，不含其他单位共享车辆 |
| 可用车数 | 上述所属车辆中已绑定有效合约且上架的数量 | 不代表当前空闲车辆数；员工可用其他单位车辆不增加此数 |

| 本月用车次数 | 当前查看范围内本月创建或用车时间发生在本月的公务车订单数量 | 显示本月用车次数 |

交互说明：每张顶部指标卡右上角显示弱提示图标。鼠标悬浮后展示该卡片主指标及关联副指标的统计口径，不占用卡片常驻展示空间。

## 4. 累计指标与较上月

使用率统一显示“较上月同期”，差值使用 % 符号展示；用车次数按原增长比例口径。不使用“同比上月”。详细公式与明细交互见《01A_Dashboard使用率统计与明细》。

### 4.1 总计公务用车次数

“总计公务用车次数”为历史累计指标，不计算与上月累计值之间的增长百分比，也不展示本月新增次数，避免与“本月用车次数”卡片重复。

卡片副文案固定显示“累计至今日”。右侧保留现有迷你折线，用于视觉表达近期上升或下降趋势，不展示较上月百分比。

统计周期：自企业启用公务车业务起，累计至当前时间。当前迷你折线仅作趋势视觉提示，不接入独立趋势数据，也不参与总计公务用车次数的计算。

### 4.2 本月使用率较上月同期

```text
使用率 = 各车计入用车时长之和 ÷ 有效服务时长之和 × 100%
较上月同期 = 本月使用率 - 上月同期使用率（展示为带正负号的 % 数值）
```

工作日取周一至周五 09:00—18:00，自然日取全天。有效服务时间取“上架与实际用车区间的并集”，用车中下架仍计入。完整区间公式、必要规则和示例见[使用率统计与明细补充](01A_Dashboard使用率统计与明细.md)。

### 4.3 本月用车次数较上月

`较上月 = (本月用车次数 - 上月同期用车次数) / 上月同期用车次数 * 100%`

结果保留 1 位小数，并根据正负值展示上升、下降或持平状态。

### 4.4 比较周期与零值规则

1. 使用率比较截取至上月对应日期的相同时分秒；上月无对应日期时取月末相同时刻。查看完整历史月时比较两个完整自然月。
2. 本月用车次数比较中，上月同期次数大于 0 时按公式计算。
3. 上月同期次数为 0、本月次数大于 0 时，展示“上月无数据”，不展示百分比。
4. 上月同期次数与本月次数均为 0 时，展示“持平”。
5. 使用率任一期有效服务时长为 0 时，比较显示“—”；两期均有分母时正常相减，包括上期使用率为 0 的情形。历史记录缺失时显示数据不完整，不当作 0。
## 5. 各分公司使用状况总览

### 5.1 总公司视角

展示各分公司的使用状况。

| 字段 | 说明 |
| --- | --- |
| 分公司 | 分公司名称 |
| 所属车辆（可用 / 总数） | 按资产归属统计：分公司所属车辆中已上架且绑定有效合约的数量 / 所属车辆总数；不含其他单位共享车辆，不表示当前空闲数 |
| 本月已完成次数 | 本月已完成公务车订单数量 |
| 本月用车时数 | 本月实际用车总时长，展示到分钟 |
| 使用率 | 按车辆资产归属及历史上下架计算，Σ有效用车时长 / Σ有效服务时长 × 100%；合计不平均各行百分比 |
| 较上月同期 | 本月使用率减去上月同期使用率，使用 % 符号展示，不改为相对增长率 |
| 预约待交次数 | 当前仍未完成的订单数量，包含已预约未完成和用车中订单 |
| 平均每次用车时数 | 本月实际用车总时长 / 本月已完成次数 |

车辆数和使用率按资产归属统计；本月订单次数、用车时长按员工所属分公司统计。其他分公司员工使用车辆，其使用率仍归车辆资产所属单位。分公司无所属车辆时车辆数显示 `0 / 0`、使用率显示“—”，员工用车数据仍可存在。总公司直属车辆只计入总公司直属及公司整体统计，不分摊到借用分公司。

### 5.2 分公司视角

展示该分公司内各车辆的使用状况。字段与总公司视角一致，分公司名称替换为车辆。

## 6. 部门用车统计

1. 统计维度支持用车时长和用车次数。
2. 总公司视角下，部门名称前显示分公司名称。
3. 分公司视角下，直接显示部门名称。
4. 图表条形长度只表示当前列表内的相对占比，计算公式为：`当前部门值 / 当前列表最大值 * 100%`。
5. 条形占比不是业务指标，不单独展示百分比；页面展示真实用车时长或用车次数。
6. 图表区域支持上下滚动，能够查看所有部门数据。

## 7. 总体用车率

总体用车率用于观察本月与上月趋势。

计算公式：

`每日使用率 = Σ当日所选口径内实际用车时长 / Σ当日有效服务时长 × 100%`

规则：

1. 每日按历史上下架、所选口径及资产归属切片计算；月度点按时长汇总，不能平均每日使用率。
2. 停用、下架后的空闲时间不计入；仍在实际用车的工作时间继续补入分母。无有效服务时长的点显示空值，不连成 0%。
3. 用车中订单按实际已发生时长计算。
4. 已完成订单按实际取还车时间计算。

## 10. 使用率明细功能

| 功能 | 要求 |
| --- | --- |
| 入口 | 使用率卡片右上角图标按钮，悬停提示“查看明细”；整张卡片不点击打开 |
| 口径与周期 | 仅在明细弹窗内切换工作日/自然日、本月/上月同期；口径同步影响卡片、总览及趋势 |
| 车辆清单 | 车牌、分公司、有效服务时长、计入用车时长、使用率、查看；可搜索、筛分公司、每页 10 条，无有效服务的车不列出 |
| 车辆详情 | 另开弹窗，提供服务流水、用车订单两个 Tab；关闭详情后保留原清单筛选与页码 |
| 服务流水 | 普通表格只保留操作时间、上架/下架、本期计入时长三列 |
| 用车订单 | 普通列表展示订单/员工、真实取还车、完整用车、本期实际和计入时长；不做展开层 |
| 下载 | 车辆清单导出全部筛选结果，车辆详情导出当前 Tab 全部记录；CSV，时长到分钟 |

详细字段及计算规则见[使用率统计与明细补充](01A_Dashboard使用率统计与明细.md)。
