## 1. 计算方式

### 1.1 时间口径

| 口径 | 计入时间 |
| --- | --- |
| 工作日（默认） | 周一至周五 09:00—18:00，连续 9 小时；不另扣午休，不另应用节假日或补班日历 |
| 自然日 | 每天全天，包含夜间和周末；本月只计至统计截止时刻 |

### 1.2 使用率公式

以下“实际用车区间”指实际取车至实际还车；未还车算到统计截止。所有区间先裁切到统计期间和车辆资产归属范围。

```text
有效服务区间 =（车辆上架区间 ∪ 订单实际用车区间）∩ 所选口径的计入时间
计入用车区间 = 订单实际用车区间 ∩ 所选口径的计入时间

有效服务时长 = 有效服务区间去重后的累计时长
计入用车时长 = 计入用车区间去重后的累计时长

单车使用率 = 计入用车时长 ÷ 有效服务时长 × 100%
公司/分公司使用率 = 范围内各车计入用车时长之和 ÷ 有效服务时长之和 × 100%
```

`∪` 为并集，任一覆盖即纳入，重叠只算一次；`∩` 为交集，只保留共同覆盖的时间。公司、分公司先加总时长再相除，不能平均各车或各分公司百分比，也不能用当前车辆数乘整月时间。

**下架后仍在用车：实际用车落在所选计入时间内的部分，同时计入分子、分母；还车后继续下架的时间不计入。**仅有预约但未实际取车不计用车时长。

### 1.3 较上月同期

```text
较上月同期 = 本月使用率 - 上月同期使用率
展示：带正负号的 % 数值，例如 60.0% - 50.0% 显示 +10.0%
```

此处仍计算两期使用率的差值，不除以上月使用率。本月从月初算至当前时刻，上月从月初算至对应日的相同时分秒；上月无对应日期时取月末相同时刻。查看完整历史月时比较两个完整自然月。两期使用相同统计口径，但分别读取各期历史车辆和上下架记录。

任一期无有效服务时长时，比较显示“—”；上月有服务但使用率为 0% 时仍正常相减。

## 2. 必要计算规则

| 项目 | 规则 |
| --- | --- |
| 统计归属 | 车辆数、使用率按车辆当时资产归属；跨分公司员工用车仍归车辆所属单位。员工订单次数、实际用车时长按员工所属分公司统计 |
| 历史范围 | 月中新增、上下架、调拨均按实际生效时间分段；调拨前后分别归属对应分公司，公司按车辆 ID 去重。已删除或调出的历史贡献车辆仍须统计 |
| 跨期订单 | 按实际用车区间与本期求交集，不按创建月或还车月筛除；取还车时间仍展示原始值 |
| 实际时长 | 普通用车时长保留非工作时间；只有使用率的计入时长按所选口径裁切 |
| 零值 | 有服务但未用车显示 0.0%；无服务显示“—”，且不出现在明细车辆列表、搜索和分页条数中 |
| 边界与精度 | 时间区间按左闭右开处理，先按原始时间戳去重、汇总再计算；使用率和同期差值保留 1 位小数，时长展示/导出向下取整到分钟，不显示秒；整小时不附加“0 分” |
| 重复数据 | 同车重叠区间只算一次；重叠订单按实际取车时间、订单 ID 排序，重复部分只归入第一条，保证计入时长可加总 |
| 状态历史 | 读取本期开始前最近一次状态作为期初依据。上架中因订单占用而暂不可再预约，仍属于服务时间；下架、停用、合约失效按生效时间结束开放区间 |
| 数据异常 | 缺少必要状态/归属记录、取车时间缺失、还车早于取车时提示“数据不完整”，不得用预约时间或当前状态补算。正常使用率应在 0%—100%，不能用截断掩盖错误 |

## 3. 计算举例

统计一个工作日，口径为 09:00—18:00：

| 车辆 | 上下架及实际用车 | 有效服务时长 | 计入用车时长 | 使用率 |
| --- | --- | ---: | ---: | ---: |
| A | 09:00 已上架，10:00 取车，12:00 下架，15:00 还车，此后未上架 | 6 小时：上架 3 小时＋下架用车补计 3 小时 | 5 小时 | 83.3% |
| B | 13:00 首次上架，14:00 取车，16:00 还车 | 5 小时 | 2 小时 | 40.0% |
| C | 09:00 已上架，11:00 下架，14:00 再上架，15:00 取车，19:00 还车 | 6 小时：09:00—11:00＋14:00—18:00 | 3 小时：15:00—18:00 | 50.0% |
| 合计 | 按时长加总 | 17 小时 | 10 小时 | 58.8% |

```text
分公司使用率 =（5＋2＋3）÷（6＋5＋6）× 100% = 58.8%
上月同期为 50.0% 时，较上月同期显示 +8.8%
```

C 的完整实际用车为 4 小时，计入使用率为 3 小时；非工作时段的 1 小时仍保留在实际用车时长中。

## 4. 原型功能说明

### 4.1 入口与弹窗操作

| 功能 | 操作与结果 |
| --- | --- |
| 打开明细 | 使用率卡片右上角小图标按钮，悬停提示“查看明细”；卡片其他区域不点击打开，说明图标仍只显示计算提示 |
| 明细范围 | 继承仪表板当前公司/分公司范围及权限；默认本月，可切换上月同期 |
| 切换口径 | 仅在明细内选择工作日/自然日；卡片标题对应显示“本月工作日使用率”/“本月自然日使用率”，同步重算卡片、总览、趋势和明细。关闭弹窗保持口径，刷新恢复工作日；订单次数和完整实际时长不受影响 |
| 汇总区 | 显示范围、统计起止时间和一行“计入用车时长 ÷ 有效服务时长 = 使用率”，数值与卡片一致 |
| 筛选与分页 | 支持车牌搜索，总公司可筛分公司；每页 10 条，按分公司、车牌排序，筛选/周期/口径变化回到第一页。筛选只影响列表，不改变范围汇总 |
| 查看单车 | 点“有效服务时长”或“查看”另开服务流水详情；点“计入用车时长”另开订单详情。原车辆列表、筛选及页码保留 |
| 详情切换与关闭 | 详情有服务流水、用车订单两个 Tab；关闭详情回到原列表，关闭主弹窗同时关闭详情 |
| 展示样式 | 主弹窗约 800px，详情约 860px，小屏不超过视口；紧凑表格，长列表内部滚动，无时间轴、展开行或子表 |

### 4.2 车辆列表

| 列 | 展示 |
| --- | --- |
| 车牌、分公司 | 分两列单行显示；按车辆 ID 关联，调拨按归属片段拆行 |
| 有效服务时长 | 本期分母，可点击打开服务流水 |
| 计入用车时长 | 本期分子，可点击打开订单列表 |
| 使用率 | 分子 ÷ 分母 × 100% |
| 操作 | 查看，默认打开服务流水 |

只展示有效服务时长大于 0 的车辆。有服务但未用车仍展示；筛选无结果时显示空状态。

### 4.3 服务流水表格

按操作时间正序，一行对应一次上架/下架，表格只保留三列：

| 列 | 展示 |
| --- | --- |
| 操作时间 | 实际生效时间；包含用于期初状态依据的前期操作，不伪造为月初发生 |
| 操作 | 上架 / 下架 |
| 本期计入时长 | 该状态区间计入本期分母的总时长，已包含下架后的实际用车补计，不另列拆分 |

下架且未用车的流水仍展示为本期计入 0；所有流水计入合计等于单车有效服务时长。下一操作时间、区间时长、关联订单及补计拆分不在页面和服务清单中展示。

### 4.4 用车订单列表

纳入实际用车与本期资产归属区间有交集的订单，包含已还车和用车中。完全位于非工作时间的订单也展示，工作日口径计入 0。

| 列 | 展示 |
| --- | --- |
| 订单 / 员工 | 订单编号、员工快照，合并一列 |
| 实际取还车 | 原实际起止时间，合并一列；未还车显示“用车中” |
| 完整用车 | 原实际取车至还车或统计截止的时长 |
| 本期实际 | 与本期及资产归属范围重叠的实际时长，包含非工作时间 |
| 计入时长 | 按当前口径裁切、去重后的时长，合计等于单车分子 |

### 4.5 下载清单

| 入口 | 下载范围 |
| --- | --- |
| 车辆列表“下载清单” | 当前范围、周期、口径及筛选条件下的全部车辆，不限当前页，不含无服务车辆 |
| 车辆详情“下载清单” | 当前 Tab 的全部服务流水或订单，不限可视滚动范围 |

下载 UTF-8 BOM CSV，可用 Excel 打开；空清单时按钮禁用。所有文件包含车牌、分公司、统计期间和口径，文件名包含清单类型、周期及口径。导出不改变筛选、页码或 Tab。

车辆清单导出有效服务、本期实际、计入分钟及使用率；服务流水只导出操作时间、操作、本期计入分钟及文件共用的车辆/统计范围信息；订单另含原实际起止、完整/本期/计入分钟、非工作及重叠扣除。各时长为整数分钟。

## 5. 开发一致性要求

1. 后端统一计算，卡片、列表、详情及下载共用同一截止时刻、快照、口径和权限。翻页与选车不改变截止时刻；快照过期统一刷新，查询失败提示重试。
2. 保留车辆上下架/失去开放资格的生效时间、资产归属历史、订单实际取还车及历史识别快照。企业之间隔离，分公司管理员不能读取其他分公司资产明细。
3. 逐订单计入时长合计等于单车分子，逐流水计入时长合计等于单车分母，逐车汇总等于卡片。先汇总后取整，展示值逐行相加可能有不足 1 分钟/行的舍入差异。
