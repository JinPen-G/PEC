# 分时租赁订单列表标签与状态说明

本文仅说明分时租赁订单列表的标签、状态、统计卡片及企业端按钮控制。

## 1. 业务与身份标签

| 标签 | 展示条件 | 说明 |
| --- | --- | --- |
| 同站租还 | 在“全部”页签查看同站租还订单 | 标识订单所属业务为同站租还；进入同站租还页签后不重复显示。 |
| 甲租乙还 | 在“全部”页签查看甲租乙还订单 | 标识订单所属业务为甲租乙还；进入甲租乙还页签后不重复显示。 |
| 企业简称，如 TSMC | 订单使用企业身份下单 | 标识该会员本次订单使用的企业身份或企业方案。该标签不代表订单一定为企业月结。 |
| 会员等级，如普通会员、金牌会员 | 订单会员存在会员等级 | 用于快速识别该订单会员的等级或会员方案。 |

## 2. 时间与据点标签

| 标签 | 展示条件 | 说明 |
| --- | --- | --- |
| 取车时间后的“今日” | 预约取车日期等于系统营运时区当天日期 | 表示预约取车发生在今天，只比较日期，不表示未来 24 小时内取车。 |
| 还车时间后的“今日” | 预约还车日期等于系统营运时区当天日期 | 表示预约还车发生在今天，只比较日期，不表示未来 24 小时内还车。 |
| 取车 / 还车 | 据点列固定展示 | 分别标识预约取车据点和预约还车据点。 |
| 橙色取车 / 还车 | 取车据点与还车据点不同 | 用于突出甲租乙还或其他异地还车订单。相同据点时使用普通样式。 |

## 3. 客户风险标签

| 标签 | 产生或展示条件 | 说明 |
| --- | --- | --- |
| 黑名单 | 会员或订单带有黑名单风险标记 | 提醒营运人员该会员存在黑名单记录，需要按风控规则处理。 |
| 证件异常 | 驾驶资格或证件资料缺失、失效、审核异常 | 提醒营运人员在取车前核对证件和可租载具资格。 |
| 需联系客户 | 已超过预约取车时间但仍未完成取车 | 提醒营运人员主动联系客户确认是否继续取车；订单后续转为爽约时可保留该历史风险标记。 |

## 4. 金额下方标签

金额下方标签用于区分订单当前结算进度和后续追加费用处理进度：

- 无追加费用时，展示订单结算状态。
- 非月结订单产生追加费用后，优先展示追缴状态和追缴金额。
- 企业月结订单始终展示“企业月结”，追加费用统一进入企业账单。

### 4.1 订单结算状态

| 标签 | 说明 |
| --- | --- |
| 未支付 | 订单应付金额尚未完成支付或预授权。 |
| 已收预授权 | 预授权已成功，最终费用尚未结算。 |
| 企业月结 | 订单费用由企业承担并进入企业月结账单，不由个人付款。 |
| 部分支付 | 已完成部分付款，仍有金额待最终结算。 |
| 已结清 | 订单应收、实收及应退金额已经处理完成。 |
| 待补缴 | 最终应收高于已收金额，仍需补收差额。 |
| 待退款 | 最终应收低于已收金额，退款尚未完成。 |
| 已退款 | 应退金额已经退回。 |

### 4.2 追加费用追缴状态

| 标签 | 说明 |
| --- | --- |
| 追缴待通知 | 已产生追加费用，尚未通知客户。 |
| 追缴已通知 | 已通知客户追加费用，等待后续付款处理。 |
| 追缴待支付 | 客户已收到追缴要求，但尚未完成支付。 |
| 企业月结追缴 | 追加费用由企业承担并进入企业账单；金额列通常仍统一显示“企业月结”。 |
| 追缴已结清 | 追加费用已经完成收款或挂账。 |

## 5. 订单主状态

| 阶段 | 状态标签 | 产生条件与说明 |
| --- | --- | --- |
| 预约阶段 | 待支付 | 订单已建立，但下单所需支付或预授权尚未完成。 |
| 预约阶段 | 已预订 | 订单已确认并占用车辆资源，等待客户取车。 |
| 预约阶段 | 逾期未取 | 已超过预约取车时间，订单仍未完成取车且尚未判定爽约。 |
| 履约阶段 | 验车中 | 已开始办理取车，车辆检查或交车资料尚未提交完成。 |
| 履约阶段 | 用车中 | 已完成取车，车辆正在租用中。 |
| 履约阶段 | 续租中 | 订单已进入续租状态，新的预约还车时间已经生效。 |
| 异常阶段 | 逾期未还 | 已超过预约还车时间，车辆仍未归还。 |
| 异常阶段 | 出险处理中 | 订单已登记事故或出险，正在处理事故、保险或定损。 |
| 结算阶段 | 待结算 | 车辆已归还或还车资料已提交，最终费用尚未确认完成。 |
| 结算阶段 | 待补缴 | 最终结算存在应收差额，等待补缴。 |
| 结算阶段 | 待退款 | 最终结算存在应退差额，等待退款。 |
| 终态 | 已完成 | 车辆已归还且费用处理完成，订单正式结束。 |
| 终态 | 已取消 | 订单在履约前被客户或营运人员取消。 |
| 终态 | 爽约 | 客户超过取车保留时间仍未取车，并已被确认爽约。 |
| 终态 | 已拒绝 | 因风控、证件或资格问题拒绝继续履约。 |
| 终态 | 已关闭 | 订单因异常原因终止并完成关闭处理，不再继续履约。 |

已取消、爽约、已拒绝、已关闭的订单在列表中整行置灰，表示订单已结束且不再进入正常履约流程。

## 6. 企业端复用时的按钮控制

企业端复用该页面时只提供订单查询和查看能力，不允许企业管理员直接处理营运订单。

### 6.1 保留按钮

| 按钮或控件 | 企业端规则 |
| --- | --- |
| 详情 | 保留，进入企业端只读订单详情。 |
| 查看费用 | 保留，只读查看当前企业承担的订单费用和追加费用。 |
| 更多筛选 / 收起筛选 / 重置 | 保留，用于查询企业订单。 |
| 运营总览 / 实时运营及统计卡片 | 保留，只用于切换统计视角和筛选订单。 |
| 导出 | 有导出权限时保留，只能导出当前企业数据。 |

### 6.2 隐藏按钮

| 位置 | 企业端不展示的按钮 |
| --- | --- |
| 页面顶部 | 新建订单。 |
| 取车处理 | 取车、继续取车、取消、标记爽约。 |
| 用车处理 | 延长、补办续租、处理事故、还车。 |
| 结算处理 | 继续结算、确认月结、支付、收款、退款。 |
| 追缴处理 | 通知客户、追缴收款。 |

企业端不得仅将以上按钮置灰，必须直接隐藏；对应写操作接口也不得向企业端账号开放。

## 7. 统计视角（V1.2 新增）

### 7.1 统计范围与联动

- 统计当前账号有权限查看的订单；跟随“全部 / 同站租还 / 甲租乙还”页签，不跟随下方搜索、日期等筛选条件，也不受分页影响。
- 营运端不按个人 / 企业身份或结算方式排除订单；企业端仅统计当前企业数据。
- 点击卡片清空其他筛选并筛选对应订单；再次点击同一卡片或点击“订单总数”取消卡片筛选。切换统计视角清除卡片筛选。
- 每张卡片内同一订单只计一次；卡片之间可能重复计数，不可直接相加。

### 7.2 运营总览

| 卡片 | 统计口径 |
| --- | --- |
| 订单总数 | 统计范围内的全部订单，不限状态。 |
| 待支付 | 主状态为“待支付”；不按金额下方“未支付”标签统计。 |
| 已预约 | 主状态为“已预订”，不含逾期未取。 |
| 用车中 | 验车中、用车中、续租中。 |
| 已还待结算 | 待结算、待补缴、待退款。 |
| 已完成 | 主状态为“已完成”。 |
| 已取消/已关闭 | 已取消、已拒绝、已关闭。 |
| 异常订单 | 逾期未取、逾期未还、出险处理中、爽约，或带任意风险标记的订单。 |

风险标记包括黑名单、证件异常、需联系客户、事故上报、违章待处理。已完成但有违章待处理的订单，同时计入“已完成”和“异常订单”。

### 7.3 实时运营

| 卡片 | 统计口径 |
| --- | --- |
| 今日待取车 | 预约取车日期为今天，且主状态为待支付、已预订、逾期未取。 |
| 2小时内待取车 | 预约取车时间在当前时间至未来2小时内（含边界），且主状态为待支付、已预订、逾期未取。 |
| 用车中 | 用车中、续租中；不含验车中、逾期未还。 |
| 今日待还车 | 预约还车日期为今天，且主状态为用车中、续租中、逾期未还。 |
| 2小时内待还车 | 预约还车时间在当前时间至未来2小时内（含边界），且主状态为用车中、续租中、逾期未还。 |
| 逾期未取 | 主状态为“逾期未取”。 |
| 逾期未还 | 主状态为“逾期未还”。 |
| 已还待结算 | 待结算、待补缴、待退款。 |

“今天”与“当前时间”按系统营运时区判断；当前原型固定模拟为 `2026-08-05 10:00`，不作为正式系统规则。两个视角的“用车中”口径不同，按以上表格执行。
