## 什么是 RIMO Rental

RIMO Rental 是面向租车营运商和企业客户的租赁平台，涵盖同站租还、甲租乙还、门市租赁、公务用车及合作通路租车券。车辆、据点、会员、订单和账务围绕同一套业务规则协作。

这个产品中心收录营运端、企业端、移动应用、教程与通知页面。每个功能都可以查看交互、页面源码和需求说明，沿图谱继续追溯它的前置条件、关联功能与平台接口。

团队在页面里讨论产品，Agent 通过 MCP 读取相同的需求、关系和源码。页面区块也可以通过 Registry 引入自己的 React 项目，预览和分发使用同一份实现。

## 如何阅读一个页面

每个功能页面使用相同的阅读顺序，可以直接跳到需要的部分：

- **预览与页面源码**：先操作界面，再查看这一页使用的源码。
- **需求要点与文档**：快速理解关键规则，必要时切换到完整说明。
- **安装与源码**：查看 Registry 命令、区块文件与依赖。
- **功能关系**：在[需求关系图谱](#/docs/graph?project={{projectId}})中定位相关需求，核对前因、后果和原文。

按 <kbd>Ctrl</kbd> <kbd>K</kbd>，或点击顶部搜索，查找车辆、订单、据点等功能。

## 公开内容与访问

当前接入的页面、需求、图谱和组件资料均可公开浏览。点击 **Try the demo** 会进入前台当前项目，无需登录。

在线协作需要登录来识别参与者。Agent 的 MCP 接入使用项目读取凭证，配置方式见[AI 和 MCP](ai.md)。

## 安装页面区块

已初始化 shadcn 的 React 19 与 TypeScript 项目，可以通过当前项目的 Registry 按需获取区块：

```sh
npx shadcn@latest add {{origin}}/r/{{projectId}}/rimo-vehicle-groups.json
```

命令会带上登记的样式、辅助文件和依赖。具体目录与手动安装方式见[使用指南](usage.md)。

## 与实际业务系统的关系

这里提供可交互的业务设计与需求上下文。订单、付款、审批和控车使用模拟状态；接入真实系统时，需要依据 PRD 实现服务端校验、权限和接口回执。

合作通路租车券当前一期需求限定同站租还。页面和图谱中的业务边界以对应版本原文为准。
