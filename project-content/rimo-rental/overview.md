# RIMO Rental

RIMO Rental 面向租车营运商和企业客户，涵盖分时租赁、公务用车与门市租赁。合作通路租車券是分时租赁的跨模式功能，当前一期 PRD 仅定义同站租还。

## 浏览产品

营运端、企业端、移动端、公开教程和通知信件按客户端组织。页面提供模拟交互，业务逻辑以关联 PRD 和业务知识库原文为依据。
