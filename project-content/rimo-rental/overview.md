# RIMO Rental 项目概况

RIMO Rental 面向租车营运商和企业客户，包含分时租赁、公务用车与门市租赁等业务。Preview 中的页面用于产品需求评审和交互演示，不执行真实租赁业务。

## 本次可查看页面

- 車型組管理：查看品牌、车型、载具类型及特性；搜索、新增、编辑、删除均为当前页面的模拟操作。
- 車輛調撥管理：按车辆、站点、服务类型筛选；演示单车与批量调拨及服务类型切换。

## 业务需求说明

当前两份页面说明依据既有营运端原型整理，状态为草案。正式业务 PRD 后续按实际需求文件接入，不能把原型模拟效果当作已实现的业务服务。

原型、页面源码和业务文档按页面公开范围读取；重要页面需要登录并由管理员授权。内部平台研发资料不属于本项目业务说明。
