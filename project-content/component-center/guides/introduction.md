## 什么是组件中心

组件中心将可复用的界面组件、页面级区块和使用说明组织在一起。预览用来检查行为，源码用来接入项目，文档说明字段、交互和依赖。

展示页直接引用组件库实现，Registry 按清单提供同一份源码。安装后，文件进入自己的项目，可以阅读、修改和继续组合，不需要把每个组件拆成一个 npm 包。

当前以车组管理区块作为接入示例。后续组件库按实际提供的源码与许可扩展，Agent 可以通过 MCP 查找已经登记的内容。

## 内容如何组织

<dl>
<div><dt>组件</dt><dd>完成独立交互的基础单元，例如输入、选择、表格和弹层。具体能力以已登记的组件目录为准。</dd></div>
<div><dt>区块</dt><dd>由多个组件组成的一段完整界面，例如查询列表、编辑表单或工作台。一个完整的业务内容页也可以作为区块。</dd></div>
<div><dt>展示页面</dt><dd>提供交互预览、源码、安装方式和说明。只引用库中的实现，不另外复制一份演示代码。</dd></div>
<div><dt>Registry</dt><dd>记录安装文件、目标目录、npm 依赖和组件依赖，为开发人员与 Agent 提供按需安装入口。</dd></div>
</dl>

组件和区块沿用统一的主题与交互约定。业务字段、模拟数据和宿主环境依赖在各自目录中维护。

## 如何阅读一个页面

- **预览与页面源码**：检查默认状态、输入、选择、加载与失败，再查看源码。
- **安装与依赖**：复制 Registry 命令，核对实际安装文件和需要的包。
- **使用说明**：确认区块的用途、字段和运行边界。
- **键盘与动效**：核对焦点、关闭顺序、触控区域和减少动态效果。

通过左侧菜单或顶部搜索定位内容。**Try the demo** 保留前台当前项目，在统一外壳中连续查看页面。

## 公开内容与访问

当前组件示例、说明与安装源码公开提供，浏览和下载无需登录。源码沿用自身的许可，接入前核对安装项列出的文件和依赖。

MCP 使用当前项目的读取凭证。在线协作需要登录，组件预览本身不依赖登录状态。

## 安装第一个区块

在已初始化 shadcn 的 React 19 与 TypeScript 项目中执行：

```sh
npx shadcn@latest add {{origin}}/r/{{projectId}}/rimo-vehicle-groups.json
```

CLI 会复制车组管理的源码、样式和辅助模块。完整步骤见[使用指南](usage.md)。

## 组件中心与应用项目

组件中心负责组织和分发可复用源码，应用项目负责真实业务、接口和权限。引入一个页面区块之后，仍需将模拟数据和操作接到自己的业务服务。
