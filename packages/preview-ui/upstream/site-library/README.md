# Site UI sources

`free-source` contains third-party React primitives, tokens and their unchanged MIT notice. The fixed upstream repository and commit are recorded in `source-manifest.json`; these sources are not original Preview code.

`browser-capture` and `auth-capture` retain the CSS/font baselines and adaptation manifests. Unused website HTML and JavaScript are preserved in the external provenance archive, not in this working tree or any release. Evidence records identify that storage explicitly.

Preview owns the project catalog, authorization, document handling and composition around these primitives. Current source copies have neutral names; original and adapted hashes are recorded separately. See [source and license notes](../../NOTICE.md).
