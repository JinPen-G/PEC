# Vendored UI primitives

This directory retains the component, token and type sources used by Preview. The original library is by Elia Kuratli and is provided under the unchanged [MIT license](LICENSE), at repository commit `8302b52ed9dc79ae7ca699b158a98dfdf09656f7`.

These are third-party sources with Preview's naming adaptations. Website promotion, generated registry downloads and the original package's CI/tooling are kept outside the application working tree. This directory is not a standalone package; dependency installation and builds use Preview's root package.json.

See the [UI source and licenses](../../../NOTICE.md) for provenance, retained original hashes and the external reference archive. The archive is never a runtime dependency.
