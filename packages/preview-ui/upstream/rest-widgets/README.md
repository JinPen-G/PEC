# Rest widget sources

Media Player and Now Playing are independently reconstructed React components supplied by the project owner. They derive their behavior and styling from public references; they are not acquired official proprietary TypeScript and are not represented as original Preview implementations.

The twelve implementation files retain their source version in `source-manifest.json`. Original hashes and current maintained hashes are distinct where naming comments changed. The host owns audio, countdown state and overlay placement; these components are not published through the component Registry.

The provenance records identify the original public references through the external archive described in [source and license notes](../../NOTICE.md). Brand normalization grants no additional rights to the original references. There is no runtime dependency on that archive or another project directory.
